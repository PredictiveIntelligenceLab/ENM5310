The point of this lecture. Many scientific datasets are not vectors but functions: fields sampled on meshes, sensors at scattered locations, solutions at whatever resolution the solver used. This lecture builds models that take functions in and give functions out, in five steps:

  1. A function can be represented by a network x↦fθ(x)x\mapsto f_\theta(x)x↦fθ​(x): a neural field.
  2. Neural fields learn smooth components before fine ones — spectral bias — and the neural tangent kernel explains why and how to fix it.
  3. One network can represent many functions if it is told which one: a conditional neural field fθ(y;z)f_\theta(y;z)fθ​(y;z).
  4. An operator G:a↦u\mathcal G: a\mapsto uG:a↦u is then an encoder a↦za\mapsto za↦z plus a conditional neural field y↦fθ(y;z)y\mapsto f_\theta(y;z)y↦fθ​(y;z). How the decoder is conditioned — globally or locally — separates DeepONet from graph, Fourier and transformer neural operators.
  5. Transformer neural operators use continuous self-attention to encode and cross-attention from continuous queries to decode.

0. Why functions, not vectors (8 min)

0.1 The data

A PDE solver returns uuu on its mesh; change the mesh and the vector changes length. A weather station network observes the atmosphere at a few thousand irregular points; the satellite record observes it on a different grid. An experiment measures a velocity field with PIV at one resolution and pressure with taps at a dozen points. In all of these, the object is a function u:D→Rduu: D\to\mathbb{R}^{d_u}u:D→Rdu​; the vector we store is an accident of how it was sampled.

Every model in this course so far took a fixed-length vector in. A CNN (Lecture 14) is better — it shares weights across positions — but its 3×33\times33×3 stencil encodes the grid spacing, so a model trained on a 64×6464\times6464×64 grid computes a different physical operator on a 128×128128\times128128×128 grid (Lecture 14 §7). We want models that are defined on functions and merely evaluated on whatever samples we have.

0.3 The loss is an integral

The natural risk compares functions, not vectors:

This is the Gaussian log-likelihood of Lecture 5, summed over points of a function. Two consequences:

  • The query points can be different for every example and every minibatch — and sampling a random subset of points is an unbiased estimate of the loss, which makes training on large fields cheap (§8).
  • A model that can be evaluated at any yyy fits this loss naturally. That is the motivation for neural fields.

Discretization invariance. Informally, a neural operator should (i) accept its input at any set of sample points, (ii) produce its output at any query points, and (iii) converge to a single operator on functions as the samples become dense (Kovachki et al., 2023). The architectures below achieve these to different degrees, and §6 says which.

Remember. Operator learning approximates G:a↦u\mathcal G: a\mapsto uG:a↦u between function spaces from solved examples. The loss is an integral over the output domain, estimated by sampling query points; the model should not care how its input and output were sampled.

1. Neural fields (8 min)

1.1 A function as a network

A neural field (or coordinate network, or implicit neural representation) represents a single function by a network that takes a coordinate in and returns the function's value:

fθ:D→Rdu,x↦fθ(x)=MLPθ(x). f_\theta: D\to\mathbb{R}^{d_u},\qquad x\mapsto f_\theta(x)=\text{MLP}_\theta(x). fθ​:D→Rdu​,x↦fθ​(x)=MLPθ​(x).

Given samples {(xj,u(xj))}j=1n\{(x_j,u(x_j))\}_{j=1}^n{(xj​,u(xj​))}j=1n​, fit θ\thetaθ by least squares, min⁡θ∑j∣fθ(xj)−u(xj)∣2\min_\theta\sum_j\lvert f_\theta(x_j)-u(x_j)\rvert^2minθ​∑j​∣fθ​(xj​)−u(xj​)∣2 — Lecture 12's regression with the coordinate as the input. The function is now stored in θ\thetaθ, not on a grid.

What this buys.

  • Any resolution. Evaluate fθf_\thetafθ​ at any point, on any grid, as many times as you like.
  • Any sampling. Fit from scattered, irregular or partial observations.
  • Derivatives. ∇xfθ\nabla_x f_\theta∇x​fθ​, Δxfθ\Delta_x f_\thetaΔx​fθ​ are exact by automatic differentiation (Lecture 13 §1), so a neural field can be constrained by a PDE. A PINN (Lecture 18) is a neural field fitted to a PDE residual instead of, or in addition to, data.
  • Compactness. For smooth signals the weights can be much smaller than a dense grid.

Neural fields are now standard for representing images, 3D shapes (signed distance functions), and radiance fields for view synthesis (NeRF; Mildenhall et al., 2020).

1.2 The catch

Fit u(x)=sin⁡(2πx)+12sin⁡(2π⋅10x)u(x) = \sin(2\pi x)+\tfrac12\sin(2\pi\cdot10x)u(x)=sin(2πx)+21​sin(2π⋅10x) on [0,1][0,1][0,1] with a ReLU or tanh MLP on raw xxx. Within a few hundred steps it captures the slow sinusoid. After many thousands it is still missing most of the fast one. Trained on a photograph, the same network produces a blurry version of it. This is not a capacity problem: by universal approximation (Lecture 12 §5) the network can represent the target. It is a property of how gradient descent fits it.

2. Spectral bias (6 min)

Spectral bias (or frequency bias) is the empirical observation that neural networks trained by gradient descent fit the low-frequency components of a target first and high-frequency components much later (Rahaman et al., 2019). Decompose the training residual r=fθ−ur = f_\theta-ur=fθ​−u into Fourier modes and track each over training: the low-kkk coefficients drop quickly, the high-kkk coefficients barely move.

It has two faces.

  • A good inductive bias for generalization in ordinary regression: among the many functions that fit noisy data, the network prefers smooth ones (compare early stopping as regularization, Lecture 13 §6).
  • A serious obstacle in scientific computing, where the high-frequency content is the physics: boundary layers, shocks, turbulence, fine microstructure. A PINN with a raw-coordinate MLP will often converge to a smooth wrong solution of a multiscale problem.

Two practical fixes are common: feed the network Fourier features of the coordinates, γ(x)=[cos⁡(2πBx),sin⁡(2πBx)]\gamma(x)=[\cos(2\pi Bx),\sin(2\pi Bx)]γ(x)=[cos(2πBx),sin(2πBx)] (Tancik et al., 2020), or use sinusoidal activations (SIREN; Sitzmann et al., 2020). To see why these work — and how to choose BBB — we need a model of the training dynamics.

3.3 Where the frequencies come in

The remaining question is what the eigenvectors of Θ\ThetaΘ look like. For inputs spread uniformly on a circle or sphere, the NTK of a standard MLP depends only on the angle between inputs, so it is rotation invariant. Rotation-invariant kernels are diagonalized by Fourier modes on the circle (spherical harmonics on the sphere) — the same reason convolutions are diagonalized by the DFT (Lecture 14 §1.2). And the eigenvalues decay with frequency: for a two-layer ReLU network on the circle, λk∝k−2\lambda_k\propto k^{-2}λk​∝k−2 (Basri et al., 2019); on the sphere Sd−1S^{d-1}Sd−1 the decay is polynomial, of order k−dk^{-d}k−d (Bietti & Mairal, 2019).

Putting it together, the frequency-kkk component of the residual behaves like

r^k(t)≈e−c t/k2 r^k(0)(two-layer ReLU, 1D), \hat r_k(t)\approx e^{-c\,t/k^{2}}\,\hat r_k(0)\qquad(\text{two-layer ReLU, 1D}), r^k​(t)≈e−ct/k2r^k​(0)(two-layer ReLU, 1D),

so learning frequency 10 takes about 100 times longer than frequency 1. That is spectral bias, derived.

3.4 Why Fourier features fix it

Feed the network γ(x)=[cos⁡(2πbr⊤x), sin⁡(2πbr⊤x)]r=1R\gamma(x) = \big[\cos(2\pi b_r^\top x),\ \sin(2\pi b_r^\top x)\big]_{r=1}^{R}γ(x)=[cos(2πbr⊤​x), sin(2πbr⊤​x)]r=1R​, with br∼N(0,σ2I)b_r\sim\mathcal N(0,\sigma^2I)br​∼N(0,σ2I). Two facts:

  1. γ(x)⊤γ(x′)=∑rcos⁡(2πbr⊤(x−x′))\gamma(x)^\top\gamma(x') = \sum_r\cos\big(2\pi b_r^\top(x-x')\big)γ(x)⊤γ(x′)=∑r​cos(2πbr⊤​(x−x′)) depends only on x−x′x-x'x−x′. This is the identity behind sinusoidal positional encodings (Lecture 17 §1.3), and it makes the NTK of the composed network approximately stationary, Θ(x,x′)≈h(x−x′)\Theta(x,x')\approx h(x-x')Θ(x,x′)≈h(x−x′).
  2. A stationary kernel is diagonalized by Fourier modes, with eigenvalues given by its Fourier transform h^(ω)\hat h(\omega)h^(ω) (Bochner's theorem, Lecture 8). So σ\sigmaσ is a bandwidth, i.e. a prior on how much fine structure the target has. Too small: spectral bias persists, and the fit is blurry. Too large: the kernel is so narrow that the network interpolates the training points with high-frequency noise and generalizes badly between them (Tancik et al., 2020). For multiscale targets, mixing several bandwidths helps (Wang, Wang & Perdikaris, 2021). The same NTK analysis explains why the different loss terms of a PINN — residual, boundary, initial condition — can train at very different rates (Wang, Yu & Perdikaris, 2022).

3.5 What the NTK does and does not say

The NTK regime is "lazy": features hardly move, and the network is a fixed kernel machine (Lecture 12 §6). Real, finite networks do learn features, and their NTK changes during training. Quantitative NTK predictions for practical networks should therefore be treated with care. The qualitative picture — residuals decay mode by mode at rates set by a kernel's spectrum, and input embeddings reshape that spectrum — holds up well in practice, and it is what you need to diagnose a neural field or a PINN that will not fit fine scales.

For standard MLPs the eigenfunctions are Fourier modes with eigenvalues decaying in frequency: spectral bias. Fourier features make the NTK stationary with a tunable bandwidth σ\sigmaσ.

4. Conditional neural fields (10 min)

4.1 Many functions, one network

A neural field represents one function. A dataset contains thousands: NNN solutions u1,…,uNu_1,\dots,u_Nu1​,…,uN​, one per input. Fitting NNN separate networks shares nothing between them. Instead, give each function a latent code zi∈Rpz_i\in\mathbb{R}^pzi​∈Rp and train one network on all of them:

ui(y)≈fθ(y;zi),i=1,…,N. u_i(y)\approx f_\theta(y;z_i),\qquad i=1,\dots,N . ui​(y)≈fθ​(y;zi​),i=1,…,N.

The weights θ\thetaθ capture what all functions have in common; the code ziz_izi​ says which one we want. This is a conditional neural field (Xie et al., 2022).

5.2 Global versus local conditioning

Global conditioning. The encoder produces one vector z=Eϕ(a)∈Rpz=E_\phi(a)\in\mathbb{R}^pz=Eϕ​(a)∈Rp, and the decoder sees the same zzz at every query point:

Local conditioning. The decoder at yyy sees a query-dependent summary of the input,

5.3 The global family

PCA-Net (Bhattacharya et al., 2021). Compute principal components {φk}\{\varphi_k\}{φk​} of the training outputs and {ψk}\{\psi_k\}{ψk​} of the training inputs. Encode aaa by its first PCA coefficients, map them through an MLP to output coefficients, and decode linearly: Gθ(a)(y)=∑k=1pzk(a) φk(y)\mathcal G_\theta(a)(y)=\sum_{k=1}^{p}z_k(a)\,\varphi_k(y)Gθ​(a)(y)=∑k=1p​zk​(a)φk​(y). Global and linear, with a fixed basis — model reduction with a learned map in between.

DeepONet (Lu et al., 2021). Learn the basis too. A branch network maps the input sampled at mmm fixed sensors to coefficients, and a trunk network maps the query point to basis functions:

Gθ(a)(y)=∑k=1pBk(a(x1),…,a(xm))⏟branch: z=E(a)  Tk(y)⏟trunk: basis+b0. \mathcal G_\theta(a)(y) = \sum_{k=1}^{p}\underbrace{B_k\big(a(x_1),\dots,a(x_m)\big)}_{\text{branch: }z=E(a)}\;\underbrace{T_k(y)}_{\text{trunk: basis}} + b_0 . In our language: global conditioning, linear last-layer conditioning, with a neural-field trunk as the learned basis. It rests on a universal approximation theorem for operators (Chen & Chen, 1995), and its error is bounded below by the ppp-width of the output set (Lanthaler et al., 2022).

NOMAD (Seidman et al., 2022). Keep the global code but replace the linear decoder with a nonlinear conditional neural field, Gθ(a)(y)=fθ(y;E(a))\mathcal G_\theta(a)(y) = f_\theta(y;E(a))Gθ​(a)(y)=fθ​(y;E(a)), e.g. by concatenation or modulation. Same bottleneck size ppp, much smaller errors on transport-dominated problems.

The trunk of a DeepONet is a neural field and suffers from spectral bias (§3): Fourier features on yyy are standard practice.

Remember. Gθ(a)(y)=fθ(y;Eϕ(a))\mathcal G_\theta(a)(y)=f_\theta(y;E_\phi(a))Gθ​(a)(y)=fθ​(y;Eϕ​(a)). Global conditioning sends one code zzz to every query — PCA-Net, DeepONet (linear in a learned basis) and NOMAD (nonlinear) — and inherits an encoder–decoder bottleneck. Local conditioning gives every query its own aggregate of input features, like attention.

  • Cost: O(nlog⁡n)O(n\log n)O(nlogn) with the FFT on a uniform grid.
  • Parameters: about kmax⁡Ddv2k_{\max}^{D}d_v^2kmaxD​dv2​ per layer in DDD dimensions, independent of the grid.

The input arrives as a set of samples {(xj,a(xj))}j=1n\{(x_j,a(x_j))\}_{j=1}^n{(xj​,a(xj​))}j=1n​ — any number, any locations.

  • It is a conditional neural field: a function of yyy, evaluable anywhere, conditioned on the token set ZZZ.

This encoder–decoder template covers several current models: attention-based encoders with cross-attention decoders (OFormer; Li et al., 2023), latent-token encoders with query decoders (Perceiver IO; Jaegle et al., 2022), models with heterogeneous and multiple inputs (GNOT; Hao et al., 2023), and vision-transformer encoders on gridded inputs combined with continuous cross-attention decoders (CViT; Wang et al., 2024).     for p in P.enc_blocks:                                         # mix latents: O(M^2)
        z = transformer_block(z, p)
    return z                                                       # (M, d) token set

8. Training, evaluation, summary (5 min)

Training. The loss of §0.3 is usually the relative L2L^2L2 error, 1N∑i∥ui−Gθ(ai)∥/∥ui∥\frac1N\sum_i\lVert u_i-\mathcal G_\theta(a_i)\rVert/\lVert u_i\rVertN1​∑i​∥ui​−Gθ​(ai​)∥/∥ui​∥, so that every example counts equally regardless of its amplitude. For models with neural-field decoders, sample a random subset of query points for each example at each step: the loss stays unbiased and memory drops from the full field to the subset. Normalize inputs and outputs (Lecture 13 §3); for multiscale outputs, tune the Fourier-feature bandwidth on validation data (§3.4).

Evaluation. Apply Lecture 13's checklist, with three additions specific to operators.

  1. Baselines. Compare against a simple model trained on the same data — a linear or PCA-based map, or a DeepONet — and against the cost of simply running the solver.
  2. Resolution. If you claim discretization invariance, test at resolutions you did not train on, and report how the error changes, not just one number.
  3. Distribution shift. Report error on inputs from the training distribution and on inputs outside it (different coefficients, geometries, longer horizons). Neural operators interpolate well within their training family; outside it, they offer no guarantee.

Summary. A neural field represents a function by a network over coordinates. Under gradient flow its residual decays mode by mode at rates set by the neural tangent kernel, which for standard MLPs favors low frequencies; Fourier features make the kernel stationary with a tunable bandwidth. A conditional neural field fθ(y;z)f_\theta(y;z)fθ​(y;z) represents a family of functions, and an operator is an encoder a↦za\mapsto za↦z followed by such a field. With global conditioning — one code for every query — we recover PCA-Net, DeepONet and NOMAD, and their bottleneck. With local conditioning — a query-dependent aggregate of the input — we get the kernel integral layer: graph NOs (learned kernel on neighborhoods), FNOs (stationary kernel in Fourier space) and transformer NOs (data-dependent kernel by attention), the last decoding by cross-attention from continuous queries.

Choosing bbb with large enough scale gives high-frequency modes large eigenvalues, so gradient descent no longer starves them.

P3. A DeepONet with p=32p=32p=32 fits diffusion problems well but performs poorly on advection of a sharp front with a random initial position. Explain, and propose two fixes.

Answer. The outputs are shifted copies of a sharp profile, a set with slowly decaying Kolmogorov ppp-width: no 32-dimensional linear space approximates all shifts well, so any linear decoder — DeepONet included — has a large error floor. Fixes: a nonlinear decoder (NOMAD-style conditioning of the field on zzz), or local conditioning (a cross-attention decoder, FNO, or graph NO), which lets each query read the relevant part of the input.
