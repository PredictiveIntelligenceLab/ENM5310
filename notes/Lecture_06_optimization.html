1. What kind of problem is this?

Before choosing a method, classify the problem. Murphy §8.1 uses four axes, and each one eliminates or admits whole families of algorithms.

Constrained or unconstrained? Everything in this course is unconstrained in form: constraints enter as penalties, and priors are the statistical name for those penalties. Genuine constraints (θ≥0\theta\ge0θ≥0, ∥θ∥≤c\|\theta\|\le c∥θ∥≤c) are handled by projection, which §10 shows is the same operation as the proximal step.

Convex or nonconvex? fff is convex iff H(θ)⪰0\mathbf{H}(\theta)\succeq0H(θ)⪰0 everywhere, strictly convex iff H≻0\mathbf{H}\succ0H≻0. Convexity buys two things: every stationary point is a global minimum, so g(θ)=0g(\theta) = 0g(θ)=0 is a complete certificate of optimality; and the minimizer set is convex, a single point under strict convexity. Neither survives into the deep learning module.

Smooth or nonsmooth? All methods in §§2–9 assume fff is differentiable. The lasso objective is not — ∥w∥1\|w\|_1∥w∥1​ has a kink at every axis — and needs §10. This is not a technicality: applying a gradient method to a nonsmooth objective produces coefficients that hover near zero without ever reaching it, which destroys the sparsity that was the point.

Local or global? For convex problems the distinction is empty. Otherwise, every method here finds a stationary point and nothing more.

Two facts to carry. First, stationarity: if θ⋆\theta^\starθ⋆ is a local minimum then g(θ⋆)=0g(\theta^\star) = 0g(θ⋆)=0, because otherwise f(θ⋆−ηg)=f(θ⋆)−η∥g∥2+O(η2)<f(θ⋆)f(\theta^\star-\eta g) = f(\theta^\star)-\eta\|g\|^2+O(\eta^2) < f(\theta^\star)f(θ⋆−ηg)=f(θ⋆)−η∥g∥2+O(η2)<f(θ⋆) for small η\etaη. A nonzero gradient is a constructive certificate of improvement. Stationary points are minima, maxima, or saddles (where H\mathbf{H}H has mixed signs).

Second, existence: a continuous coercive fff — one with f(θ)→∞f(\theta)\to\inftyf(θ)→∞ as ∥θ∥→∞\|\theta\|\to\infty∥θ∥→∞ — attains its minimum. This is exactly what separability destroys (Lecture 5 §8): the logistic NLL decreases along the ray αw0\alpha w_0αw0​, so it is not coercive and the infimum is never attained. Adding 12τ2∥w∥2\frac{1}{2\tau^2}\|w\|^22τ21​∥w∥2 restores coercivity. In optimization language, the prior makes the objective coercive and strictly convex, so the minimizer exists and is unique; §4 adds that it also improves conditioning.

2. Descent directions and step sizes

Every method in §§2–9 has the form θk+1=θk+ηkdk\theta_{k+1} = \theta_k + \eta_k d_kθk+1​=θk​+ηk​dk​. Two choices: the direction dkd_kdk​, and the step size ηk\eta_kηk​.

2.1 Descent directions

Descent direction. ddd is a descent direction at θ\thetaθ if d⊤g(θ)<0d^\top g(\theta) < 0d⊤g(θ)<0.

The name is earned by a one-line Taylor expansion: f(θ+ηd)=f(θ)+η d⊤g+O(η2)f(\theta+\eta d) = f(\theta) + \eta\,d^\top g + O(\eta^2)f(θ+ηd)=f(θ)+ηd⊤g+O(η2), so a descent direction guarantees the objective can be decreased by a small enough step.

Where do descent directions come from? Take the first-order model f(θ+δ)≈f(θ)+g⊤δf(\theta+\delta)\approx f(\theta)+g^\top\deltaf(θ+δ)≈f(θ)+g⊤δ, which is unbounded below and so must be minimized over a trust region. With δ⊤Aδ≤r2\delta^\top A\delta\le r^2δ⊤Aδ≤r2 for A≻0A\succ0A≻0, the Lagrangian g⊤δ+λ(δ⊤Aδ−r2)g^\top\delta+\lambda(\delta^\top A\delta-r^2)g⊤δ+λ(δ⊤Aδ−r2) gives g+2λAδ=0g+2\lambda A\delta = 0g+2λAδ=0, so

 δ⋆  ∝  − A−1g. (2.1)\boxed{\ \delta^\star \;\propto\; -\,A^{-1}g .\ } \tag{2.1} δ⋆∝−A−1g. ​(2.1)

Every method in this lecture is a choice of AAA. Gradient descent takes A=IA = IA=I, asserting all coordinates of θ\thetaθ are in comparable units — usually false (§4). Newton takes A=HA = \mathbf{H}A=H. L-BFGS approximates H\mathbf{H}H. Adam takes AAA diagonal, estimated online. And any A≻0A\succ0A≻0 gives a descent direction, since (−A−1g)⊤g=−g⊤A−1g<0(-A^{-1}g)^\top g = -g^\top A^{-1}g < 0(−A−1g)⊤g=−g⊤A−1g<0 — so preconditioning is always safe, and the only question is whether it helps.

2.2 Step sizes

Three strategies, in increasing order of robustness and cost.

Constant η\etaη. Simplest, and what §3 analyzes. Requires knowing the stability threshold, which §3.2 supplies.

Decaying ηk\eta_kηk​. Necessary once gradients are stochastic (§8.2). Unnecessary overhead when they are not.

Line search. Choose ηk\eta_kηk​ per step by looking at the function. Exact line search, ηk=arg⁡min⁡ηf(θk+ηdk)\eta_k = \arg\min_\eta f(\theta_k+\eta d_k)ηk​=argminη​f(θk​+ηdk​), is rarely worth its cost. What is worth it is backtracking with the Armijo condition: accept η\etaη only if it delivers a fraction ccc of the decrease the linear model promised,

f(θk+ηdk)  ≤  f(θk)+c η dk⊤gk,c≈10−4.f(\theta_k+\eta d_k) \;\le\; f(\theta_k) + c\,\eta\,d_k^\top g_k, \qquad c\approx10^{-4}.f(θk​+ηdk​)≤f(θk​)+cηdk⊤​gk​,c≈10−4.

Algorithm: backtracking line search. Given θk\theta_kθk​, descent direction dkd_kdk​, η←ηinit\eta\leftarrow\eta_{\text{init}}η←ηinit​ (use 111 for Newton-type directions), c=10−4c = 10^{-4}c=10−4, β=0.5\beta = 0.5β=0.5: repeat η←βη\eta\leftarrow\beta\etaη←βη until the Armijo condition holds; return η\etaη.

This costs one or two extra function evaluations per step and removes step-size tuning entirely for full-batch problems. Use it with Newton (§5) and L-BFGS (§6). It is not usable with stochastic gradients, since fff itself is then only estimated — which is why the deep learning half of the course is full of hand-tuned learning rates while the classical half is not.

3. Convergence rates and the condition number

This is the analytical core; everything later refers to it. Analyze the exact quadratic

f(θ)=f⋆+12(θ−θ⋆)⊤H(θ−θ⋆),H≻0,g(θ)=H(θ−θ⋆).f(\theta) = f^\star + \tfrac12(\theta-\theta^\star)^\top\mathbf{H}(\theta-\theta^\star), \qquad \mathbf{H}\succ0, \qquad g(\theta) = \mathbf{H}(\theta-\theta^\star).f(θ)=f⋆+21​(θ−θ⋆)⊤H(θ−θ⋆),H≻0,g(θ)=H(θ−θ⋆).

3.2 Stability: the step-size threshold

Convergence requires ∣1−ηλj∣<1|1-\eta\lambda_j|<1∣1−ηλj​∣<1 for every jjj, hence

 0<η<2λmax⁡ \boxed{\ 0<\eta<\frac{2}{\lambda_{\max}}\ } 0<η<λmax​2​ ​

Three regimes, each recognizable from a loss curve:

The mechanism, in one sentence: λmax⁡\lambda_{\max}λmax​ sets a ceiling on the step size, λmin⁡\lambda_{\min}λmin​ determines how much progress that step makes, and κ\kappaκ is the ratio — so a single stiff direction throttles every other direction. 4. Standardization and preconditioning

Section 3 says iteration count is proportional to κ\kappaκ. Where does κ\kappaκ come from? Uncomfortably: from how you chose to write down your features.

Feature scaling. For both our models H\mathbf{H}H is built from Φ\PhiΦ. Rescale the jjj-th column by ccc — measuring a length in nanometres instead of metres — so Φ→ΦC\Phi\to\Phi CΦ→ΦC with C=diag⁡(1,…,c,…,1)C = \operatorname{diag}(1,\dots,c,\dots,1)C=diag(1,…,c,…,1) and

H ⟶ C H C.\mathbf{H}\ \longrightarrow\ C\,\mathbf{H}\,C .H ⟶ CHC.

The eigenvalues move and κ\kappaκ can change by orders of magnitude through a change of units alone. Take one dataset, one solver, one initialization, two scalings: the same problem statistically — identical models, minimizers related by w→C−1ww\to C^{-1}ww→C−1w, identical predictions — yet one run converges in tens of iterations and the other in tens of thousands. A practitioner who does not know this diagnoses "the model won't train," changes the architecture, and never finds out.

So standardize the columns of Φ\PhiΦ to zero mean and unit variance before fitting anything (Murphy §10.2.8). This is not cosmetic tidying; it is a direct intervention on κ\kappaκ and the cheapest optimization improvement available. It is also incomplete — it equalizes the diagonal of Φ⊤Φ\Phi^\top\PhiΦ⊤Φ, while correlated features leave the off-diagonal structure and hence the conditioning bad. The same singular values djd_jdj​ that governed ridge shrinkage in Lecture 4 §9 govern κ\kappaκ here.

Preconditioning. Rather than rescaling the data, rescale the steps. From (2.1) with A=P≻0A = P\succ0A=P≻0, the recursion becomes ek+1=(I−ηP−1H)eke_{k+1} = (I-\eta P^{-1}\mathbf{H})e_kek+1​=(I−ηP−1H)ek​, so the rate is governed by κ(P−1H)\kappa(P^{-1}\mathbf{H})κ(P−1H). Choose PPP so that P−1HP^{-1}\mathbf{H}P−1H is well conditioned and solving Pz=gPz = gPz=g is cheap — requirements that pull against each other:

5. Newton's method

Section 2 built a linear model, which has no minimum, so a trust radius had to be imposed from outside and survived into the algorithm as η\etaη. The repair is a model that does have a minimum. Expand to second order, discard the O(∥δ∥3)O(\|\delta\|^3)O(∥δ∥3) remainder, and minimize what remains exactly: ∇δ[gk⊤δ+12δ⊤Hkδ]=gk+Hkδ=0\nabla_\delta\big[g_k^\top\delta+\frac12\delta^\top\mathbf{H}_k\delta\big] = g_k+\mathbf{H}_k\delta = 0∇δ​[gk⊤​δ+21​δ⊤Hk​δ]=gk​+Hk​δ=0, giving the Newton step

 Hk δk=−gk,θk+1=θk+ηkδk  (ηk=1 by default). \boxed{\ \mathbf{H}_k\,\delta_k = -g_k, \qquad \theta_{k+1} = \theta_k + \eta_k\delta_k\ \ (\eta_k = 1 \text{ by default}).\ } Hk​δk​=−gk​,θk+1​=θk​+ηk​δk​  (ηk​=1 by default). ​

No step size was invented. A positive-definite quadratic model is bounded below, so the step length is an output of the curvature rather than an input. In the Hessian eigenbasis, −H−1g-\mathbf{H}^{-1}g−H−1g multiplies the jjj-th gradient component by 1/λj1/\lambda_j1/λj​ — long steps along flat directions, short along steep. Compare §3, where the whole difficulty was one scalar η\etaη serving both λmax⁡\lambda_{\max}λmax​ and λmin⁡\lambda_{\min}λmin​.

Solve the system; do not invert. Implement as a Cholesky factorization and two triangular solves — the same reflex as the normal equations in Lecture 4 §6.

What exactness buys. On an exact quadratic the remainder vanishes and one step lands on θ⋆\theta^\starθ⋆ from any start; against §3, where the same problem cost Θ(κ)\Theta(\kappa)Θ(κ) iterations. The condition number has not disappeared — it now prices the linear solve, a cost paid once per step rather than an iteration count paid repeatedly. Near a minimum with H≻0\mathbf{H}\succ0H≻0, convergence is quadratic, ∥ek+1∥≤C∥ek∥2\|e_{k+1}\|\le C\|e_k\|^2∥ek+1​∥≤C∥ek​∥2: correct digits roughly double per iteration, 10−2→10−4→10−810^{-2}\to10^{-4}\to10^{-8}10−2→10−4→10−8, and the run terminates.

Damping, and it is not optional. Far from the optimum the quadratic model may describe fff poorly and the raw step can overshoot or increase the objective. Use backtracking (§2.2) starting from η=1\eta = 1η=1; near the optimum ηk=1\eta_k = 1ηk​=1 is always accepted, so the quadratic rate survives where it matters. If Hk\mathbf{H}_kHk​ is singular or indefinite, the model is flat or unbounded below and δk\delta_kδk​ is undefined or ascending; solve (Hk+γI)δk=−gk(\mathbf{H}_k+\gamma I)\delta_k = -g_k(Hk​+γI)δk​=−gk​ instead, which interpolates Newton (γ→0\gamma\to0γ→0) and gradient descent with step 1/γ1/\gamma1/γ (γ→∞\gamma\to\inftyγ→∞). A Gaussian prior contributes exactly this term with γ=τ−2\gamma = \tau^{-2}γ=τ−2: the prior damps Newton for free.

Affine invariance. Reparameterize θ=Aθ~\theta = A\tilde\thetaθ=Aθ~. Then g~=A⊤g\tilde g = A^\top gg~​=A⊤g, H~=A⊤HA\tilde{\mathbf{H}} = A^\top\mathbf{H}AH~=A⊤HA, so

δ~=−(A⊤HA)−1A⊤g=−A−1H−1g=A−1δ,\tilde\delta = -\big(A^\top\mathbf{H}A\big)^{-1}A^\top g = -A^{-1}\mathbf{H}^{-1}g = A^{-1}\delta,δ~=−(A⊤HA)−1A⊤g=−A−1H−1g=A−1δ,

exactly the original step in the new coordinates. Newton takes the same iterates however features are scaled or linearly recombined — the pathology of §4 vanishes identically. In the language of (2.1), Newton is A=HA = \mathbf{H}A=H: it measures smallness by the curvature of the function itself, the only choice importing no convention about the units of θ\thetaθ.

Why it is abandoned at scale. Forming H\mathbf{H}H costs O(ND2)O(ND^2)O(ND2), storing it O(D2)O(D^2)O(D2), factoring it O(D3)O(D^3)O(D3) per iteration. Free at D=10D = 10D=10, painful at D=104D = 10^4D=104, impossible at D=109D = 10^9D=109. Hence the trade that recurs all semester: gradient descent is cheap per iteration and needs O(κ)O(\kappa)O(κ) iterations; Newton is expensive per iteration and needs a handful. Which wins is a question about DDD and κ\kappaκ.

6. Quasi-Newton: BFGS and L-BFGS

The obvious middle ground: approximate H−1\mathbf{H}^{-1}H−1 without ever forming H\mathbf{H}H.

The information is already available. Consecutive iterates give sk=θk+1−θks_k = \theta_{k+1}-\theta_ksk​=θk+1​−θk​ and yk=gk+1−gky_k = g_{k+1}-g_kyk​=gk+1​−gk​, and by the mean value theorem yk≈Hsky_k\approx\mathbf{H}s_kyk​≈Hsk​. So any approximation Bk+1≈HB_{k+1}\approx\mathbf{H}Bk+1​≈H should satisfy the secant condition Bk+1sk=ykB_{k+1}s_k = y_kBk+1​sk​=yk​ — a set of DDD linear constraints on H\mathbf{H}H, obtained free of charge from gradients you computed anyway.

BFGS picks the update satisfying the secant condition that is closest to the previous BkB_kBk​ and preserves positive definiteness, which turns out to be a rank-two correction. Maintaining the inverse directly makes each step O(D2)O(D^2)O(D2) with no linear solve. L-BFGS ("limited memory") stores only the last mmm pairs (sk,yk)(s_k,y_k)(sk​,yk​), typically m=10m = 10m=10–202020, and reconstructs the action of Bk−1B_k^{-1}Bk−1​ on a vector by a two-loop recursion costing O(mD)O(mD)O(mD) — no D×DD\times DD×D matrix is ever formed.

Practical guidance. For smooth, deterministic, full-batch problems of moderate size, L-BFGS with backtracking is the default, and it requires no learning rate. It is what scipy.optimize.minimize(method='L-BFGS-B') runs, and it will beat hand-tuned gradient descent on essentially every problem in the first half of this course.

When it fails. Quasi-Newton methods depend on yky_kyk​ being an accurate gradient difference. Under minibatch sampling, yky_kyk​ is dominated by sampling noise rather than curvature, and the approximation degrades badly. That is the central reason the deep learning module uses the SGD family instead — not that second-order information is unhelpful, but that it cannot be estimated cheaply from noisy gradients.

7. IRLS for logistic regression

For logistic regression the Newton step has a closed form requiring no new machinery: each step is a weighted linear regression of the kind solved in Lecture 4. Substitute g=Φ⊤(μ−y)g = \Phi^\top(\mu-y)g=Φ⊤(μ−y) and H=Φ⊤SΦ\mathbf{H} = \Phi^\top S\PhiH=Φ⊤SΦ, then factor Φ⊤S\Phi^\top SΦ⊤S out of the bracket:

8. Stochastic gradient descent

Every objective so far is a finite sum, f(θ)=1N∑nfn(θ)f(\theta) = \frac1N\sum_n f_n(\theta)f(θ)=N1​∑n​fn​(θ), so one gradient costs O(N)O(N)O(N). When NNN is 10610^6106, a single gradient descent step is unaffordable and §3 says thousands are needed.

Halving η\etaη halves it — a flattened curve that drops sharply the moment the learning rate is reduced is not something being "unstuck," the floor shrank. 8.2 Step-size schedules and iterate averaging

To converge, η\etaη must decay: fast enough that the floor vanishes, slowly enough that the iterates can still travel the initial distance. The Robbins–Monro conditions are

∑kηk=∞(steps can cover any distance),∑kηk2<∞(accumulated noise is finite),\sum_k\eta_k = \infty \quad\text{(steps can cover any distance)}, \qquad \sum_k\eta_k^2<\infty \quad\text{(accumulated noise is finite)},k∑​ηk​=∞(steps can cover any distance),k∑​ηk2​<∞(accumulated noise is finite),

satisfied by ηk=η0(1+k)−a\eta_k = \eta_0(1+k)^{-a}ηk​=η0​(1+k)−a precisely for a∈(12,1]a\in(\frac12,1]a∈(21​,1]. In practice one uses a constant rate followed by step or cosine decay — a coarse approximation chosen because the constant phase makes rapid progress while the floor is still smaller than the distance remaining.

Iterate averaging is the cheap alternative. Rather than decaying η\etaη, run at a constant rate and return θˉK=1K−K0∑k>K0θk\bar\theta_K = \frac{1}{K-K_0}\sum_{k>K_0}\theta_kθˉK​=K−K0​1​∑k>K0​​θk​, discarding a burn-in. Since the iterates are wandering in a ball around θ⋆\theta^\starθ⋆ with roughly stationary statistics, averaging cancels much of the noise — the same variance reduction Monte Carlo gives in Lecture 1. It costs one extra vector and is worth trying before elaborate schedules.

The batch-size trade. Variance falls as 1/B1/B1/B but cost grows as BBB, so per unit computation small batches often make more progress — until hardware parallelism means a larger batch costs no more wall-clock time. The right batch size is a statement about your hardware as much as your problem.

10. Nonsmooth objectives: proximal gradient

Lecture 5 §2.2 derived lasso as MAP under a Laplace prior and deferred its optimization to here. The objective

f(w)=L(w)⏟smooth+λ∥w∥1⏟nonsmoothf(w) = \underbrace{L(w)}_{\text{smooth}}+\underbrace{\lambda\|w\|_1}_{\text{nonsmooth}}f(w)=smoothL(w)​​+nonsmoothλ∥w∥1​​​

has a kink wherever a coordinate is zero, which is exactly where the solution wants to be. Gradient descent cannot be applied — and the naive fix, subgradient descent using any element of ∂∣w∣=sign⁡(w)\partial|w| = \operatorname{sign}(w)∂∣w∣=sign(w) for w≠0w\ne0w=0, [−1,1][-1,1][−1,1] at 000, converges at a dismal O(1/k)O(1/\sqrt k)O(1/k​) and never produces exact zeros, so the sparsity that motivated lasso is lost to floating-point noise.

The right tool splits the objective. Define the proximal operator of a convex function RRR:

prox⁡ηR(v)  ≜  arg⁡min⁡u{12∥u−v∥22+ηR(u)},\operatorname{prox}_{\eta R}(v) \;\triangleq\; \arg\min_u\Big\{\tfrac12\|u-v\|_2^2+\eta R(u)\Big\},proxηR​(v)≜argumin​{21​∥u−v∥22​+ηR(u)},

which asks for a point near vvv that also makes RRR small. The proximal gradient method then takes a gradient step on the smooth part and a prox step on the rest:

 wk+1=prox⁡ηλ∥⋅∥1(wk−η∇L(wk)). \boxed{\ w_{k+1} = \operatorname{prox}_{\eta\lambda\|\cdot\|_1}\big(w_k-\eta\nabla L(w_k)\big).\ } wk+1​=proxηλ∥⋅∥1​​(wk​−η∇L(wk​)). ​

For the ℓ1\ell_1ℓ1​ norm the prox is available in closed form. The objective separates across coordinates, so solve the scalar problem min⁡u12(u−v)2+ηλ∣u∣\min_u\frac12(u-v)^2+\eta\lambda|u|minu​21​(u−v)2+ηλ∣u∣. Its subgradient condition is u−v+ηλ ∂∣u∣∋0u-v+\eta\lambda\,\partial|u|\ni0u−v+ηλ∂∣u∣∋0. If u>0u>0u>0 then u=v−ηλu = v-\eta\lambdau=v−ηλ, consistent when v>ηλv>\eta\lambdav>ηλ; if u<0u<0u<0 then u=v+ηλu = v+\eta\lambdau=v+ηλ, consistent when v<−ηλv<-\eta\lambdav<−ηλ; otherwise 0∈∂0\in\partial0∈∂ at u=0u = 0u=0. prox⁡ηλ∥⋅∥1(v)d=sign⁡(vd) max⁡(∣vd∣−ηλ, 0).\operatorname{prox}_{\eta\lambda\|\cdot\|_1}(v)_d = \operatorname{sign}(v_d)\,\max\big(|v_d|-\eta\lambda,\ 0\big).proxηλ∥⋅∥1​​(v)d​=sign(vd​)max(∣vd​∣−ηλ, 0).

11. A practical checklist

  1. Standardize the columns of Φ\PhiΦ. Always, before anything else (§4).
  2. Check your gradient against central finite differences before every experiment. This catches more bugs than any other single habit.
  3. Choose a method by DDD, NNN, and smoothness:
    • Smooth, DDD small, full batch →\to→ Newton or IRLS with backtracking (§5, §7). No learning rate to tune.
    • Smooth, DDD moderate, full batch →\to→ L-BFGS with backtracking (§6). Still no learning rate.
    • Smooth, NNN large →\to→ SGD family; Adam as a default (§9).
    • Nonsmooth penalty →\to→ proximal gradient / ISTA (§10).
    • Hard constraints →\to→ projected gradient (§10).
  4. Set the learning rate from the threshold, not by guessing. Find the largest η\etaη that does not diverge, then use a fraction of it (§3.2).
  5. Terminate on ∥g∥∞\|g\|_\infty∥g∥∞​, not on the change in objective (§7).
  6. Diagnose failures in this order:
    • Loss oscillates and grows →\to→ η\etaη above 2/λmax⁡2/\lambda_{\max}2/λmax​. Reduce it (§3.2).
    • Loss decreases monotonically but far too slowly →\to→ conditioning. Standardize, precondition, or switch to a second-order method (§4).
    • Loss plateaus while ∥g∥\|g\|∥g∥ remains large and noisy →\to→ stochastic noise floor. Decay η\etaη, raise BBB, or average iterates (§8).
    • Loss plateaus with ∥g∥→0\|g\|\to0∥g∥→0 but a poor objective value →\to→ a saddle or a genuine stationary point; restart from a different initialization.
  7. Never blame the model before ruling out 1, 4, and 6.

A closing note on nonconvexity. Everything above was derived for convex problems, and nothing in the second half of this course is convex. At a critical point of a generic high-dimensional function the Hessian's eigenvalues have effectively arbitrary signs, and a minimum requires all DDD to be positive, so most critical points are saddles rather than local minima. What is lost is global optimality, uniqueness, and any certificate. What survives — and this is why the lecture was worth doing — is every local statement: the threshold η<2/λmax⁡\eta<2/\lambda_{\max}η<2/λmax​ still governs divergence, conditioning still governs progress along a valley, and the floor vj≈ησj2/2λjv_j\approx\eta\sigma_j^2/2\lambda_jvj​≈ησj2​/2λj​ still describes where a stochastic run plateaus. When a network refuses to train, the diagnosis is almost always one of these three.
