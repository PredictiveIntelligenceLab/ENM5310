The point of this lecture. Lecture 19 ended with one equation: an operator model is an encoder followed by a conditional neural field,

Gθ(a)(y)=fθ(y; Eϕ(a)). \mathcal G_\theta(a)(y) = f_\theta\big(y;\,E_\phi(a)\big). Gθ​(a)(y)=fθ​(y;Eϕ​(a)).

Today we use it to organize the main architectures. The organizing question is what the decoder at a query point yyy gets to see. If it sees one global code, we get DeepONet and its relatives, and a provable limitation. If it sees a query-dependent summary of the input — a kernel integral — we get graph neural operators, Fourier neural operators, and attention-based neural operators, which differ only in how they parameterize the kernel.

0. The lens: operators as conditional neural fields (12 min)

0.1 The decomposition

Every architecture in this lecture fits

Gθ(a)(y)=fθ(y; conditioning(a,y)), \mathcal G_\theta(a)(y) = f_\theta\big(y;\ \text{conditioning}(a,y)\big), Gθ​(a)(y)=fθ​(y; conditioning(a,y)),

an encoder that processes the input function, observed at {(xj,a(xj))}j=1n\{(x_j,a(x_j))\}_{j=1}^n{(xj​,a(xj​))}j=1n​, and a decoder that is a conditional neural field in the query coordinate yyy (Lecture 19 §4). The decisive design choice is whether the conditioning depends on yyy.

0.2 Global conditioning

The encoder produces one vector, and every query sees the same one:

Gθ(a)(y)=fθ(y;z),z=Eϕ(a)∈Rp. \mathcal G_\theta(a)(y) = f_\theta(y;z),\qquad z=E_\phi(a)\in\mathbb{R}^p . Gθ​(a)(y)=fθ​(y;z),z=Eϕ​(a)∈Rp.

All information about aaa that the output can use passes through ppp numbers. This is the RNN encoder–decoder of Lecture 16 §0, with its single context vector: a bottleneck.

0.3 Local conditioning

Each query sees its own summary of the input, built by weighting input features by their relevance to yyy:

Gθ(a)(y)=fθ(y; c(y)),c(y)=∑j=1nwj κθ(y,xj) hj  ≈  ∫Dκθ(y,x) h(x) dx, \mathcal G_\theta(a)(y) = f_\theta\big(y;\,c(y)\big),\qquad c(y)=\sum_{j=1}^{n}w_j\,\kappa_\theta(y,x_j)\,h_j\;\approx\;\int_D\kappa_\theta(y,x)\,h(x)\,dx , Gθ​(a)(y)=fθ​(y;c(y)),c(y)=j=1∑n​wj​κθ​(y,xj​)hj​≈∫D​κθ​(y,x)h(x)dx,

where hjh_jhj​ are encoded features of the input near xjx_jxj​ and wjw_jwj​ are quadrature weights. This is attention (Lecture 16 §1): a fresh context for every output location, so there is no fixed bottleneck.

Remember. Ask of any operator model: does the decoder at yyy see one global code, or a yyy-dependent integral of the input? The first gives a bottleneck; the second gives kernel-integral architectures, distinguished by how they parameterize the kernel.

1. DeepONet, its linear decoder, and the nnn-width barrier (18 min)

1.1 The architecture

DeepONet (Lu et al., 2021) has two networks. The branch network takes the input function at mmm fixed sensor locations and returns ppp coefficients; the trunk network takes a query location and returns ppp basis functions:

Gθ(a)(y)=∑k=1pBk(a(x1),…,a(xm))⏟branch  Tk(y)⏟trunk  +  b0. \mathcal G_\theta(a)(y) = \sum_{k=1}^{p}\underbrace{B_k\big(a(x_1),\dots,a(x_m)\big)}_{\text{branch}}\;\underbrace{T_k(y)}_{\text{trunk}}\;+\;b_0 . Gθ​(a)(y)=k=1∑p​branchBk​(a(x1​),…,a(xm​))​​trunkTk​(y)​​+b0​.

In the language of §0: the branch is the encoder, z=B(a)∈Rpz=B(a)\in\mathbb{R}^pz=B(a)∈Rp; the trunk is a neural field; and the decoder is linear in zzz — conditioning enters only at the last layer, as coefficients of a learned basis. Global conditioning, linear decoder.

It is backed by a universal approximation theorem for operators (Chen & Chen, 1995): for any continuous operator G\mathcal GG on a compact set of input functions and any ε>0\varepsilon>0ε>0, there are ppp, mmm, sensor locations and networks B,TB,TB,T such that the error above is below ε\varepsilonε uniformly. As in Lecture 12, this says nothing about how large ppp must be. The rest of this section answers that.

Three practical notes.

  • The trunk is a neural field and inherits spectral bias (Lecture 19 §3); Fourier features on yyy are standard.
  • The output side is discretization-invariant — query anywhere — but the input side is not: the branch requires the input at the same mmm sensors for every example. Data on varying meshes must be interpolated to the sensors first.
  • Variants fix the basis instead of learning it: POD-DeepONet uses the leading principal components of the training outputs as the trunk (Lu et al., 2022), which is PCA-Net (Bhattacharya et al., 2021) with a neural encoder.

1.2 The barrier: any linear decoder is limited by PCA

Whatever the branch and trunk, every DeepONet output lies in the fixed affine subspace b0+span⁡{T1,…,Tp}b_0+\operatorname{span}\{T_1,\dots,T_p\}b0​+span{T1​,…,Tp​}. So its error can be no smaller than the error of the best possible ppp-dimensional subspace. On average over the data distribution, that best subspace is found by PCA (Lecture 4):

  1. Let λ1≥λ2≥⋯\lambda_1\ge\lambda_2\ge\cdotsλ1​≥λ2​≥⋯ be the eigenvalues of the covariance operator of the output distribution G#μ\mathcal G_\#\muG#​μ, with eigenfunctions φk\varphi_kφk​ (the principal components of the output functions).
  2. Among all ppp-dimensional subspaces VpV_pVp​, the expected squared distance Eu[min⁡v∈Vp∥u−v∥2]\mathbb E_u\big[\min_{v\in V_p}\lVert u-v\rVert^2\big]Eu​[minv∈Vp​​∥u−v∥2] is minimized by Vp=span⁡{φ1,…,φp}V_p=\operatorname{span}\{\varphi_1,\dots,\varphi_p\}Vp​=span{φ1​,…,φp​}, with value ∑k>pλk\sum_{k>p}\lambda_k∑k>p​λk​ — the Eckart–Young result in function space.
  3. A linear decoder outputs a point of a fixed ppp-dimensional subspace (after subtracting the mean), so it cannot beat the best one:
Ea∼μ∥G(a)−Gθ(a)∥L22  ≥  ∑k>pλk. \mathbb E_{a\sim\mu}\big\lVert\mathcal G(a)-\mathcal G_\theta(a)\big\rVert_{L^2}^2\;\ge\;\sum_{k>p}\lambda_k . Ea∼μ​∥∥​G(a)−Gθ​(a)∥∥​L22​≥k>p∑​λk​.

This is the lower bound of Lanthaler, Mishra & Karniadakis (2022). Its worst-case version is the Kolmogorov ppp-width of the output set K=G(A)\mathcal K=\mathcal G(\mathcal A)K=G(A),

dp(K)=inf⁡dim⁡Vp=p sup⁡u∈K min⁡v∈Vp∥u−v∥, d_p(\mathcal K) = \inf_{\dim V_p=p}\ \sup_{u\in\mathcal K}\ \min_{v\in V_p}\lVert u-v\rVert , dp​(K)=dimVp​=pinf​ u∈Ksup​ v∈Vp​min​∥u−v∥,

the best uniform error achievable by any ppp-dimensional linear space. No training, data or branch network can push a linear decoder below these numbers. The eigenvalue decay of the output distribution sets the price of linear decoding.

1.3 When the barrier bites: transport

Diffusion smooths, so its solutions have rapidly decaying spectra and few principal components suffice. Transport does the opposite: it moves features without smoothing them. Take the simplest case, a fixed profile φ\varphiφ translated by a random shift on the periodic domain [0,1)[0,1)[0,1):

us(x)=φ(x−s),s∼U[0,1). u_s(x) = \varphi(x-s),\qquad s\sim\mathcal U[0,1). us​(x)=φ(x−s),s∼U[0,1).

This family is one-dimensional — a single number sss identifies each function. But:

  1. The covariance C(x,x′)=Es[us(x)us(x′)]=∫01φ(x−s)φ(x′−s) dsC(x,x')=\mathbb E_s[u_s(x)u_s(x')] = \int_0^1\varphi(x-s)\varphi(x'-s)\,dsC(x,x′)=Es​[us​(x)us​(x′)]=∫01​φ(x−s)φ(x′−s)ds depends only on x−x′x-x'x−x′. It is stationary.
  2. A stationary covariance on a periodic domain is diagonalized by Fourier modes, with eigenvalue ∣φ^(k)∣2|\hat\varphi(k)|^2∣φ^​(k)∣2 for each of cos⁡2πkx\cos 2\pi kxcos2πkx and sin⁡2πkx\sin 2\pi kxsin2πkx (Lecture 14 §1.2, again).
  3. So the PCA tail is the tail of φ\varphiφ's power spectrum: keeping all frequencies up to KKK uses p≈2Kp\approx2Kp≈2K basis functions and leaves error ∑∣k∣>K∣φ^(k)∣2\sum_{|k|>K}|\hat\varphi(k)|^2∑∣k∣>K​∣φ^​(k)∣2.

For a smooth bump the spectrum decays exponentially, and a few dozen modes suffice. For a square pulse of width 12\tfrac1221​, ∣φ^(k)∣2=sin⁡2(πk/2)/(πk)2|\hat\varphi(k)|^2 = \sin^2(\pi k/2)/(\pi k)^2∣φ^​(k)∣2=sin2(πk/2)/(πk)2, which decays only like k−2k^{-2}k−2. Summing the tail and dividing by ∥φ∥2=12\lVert\varphi\rVert^2=\tfrac12∥φ∥2=21​ gives a relative error of about

∥u−Gθ(a)∥∥u∥  ≳  2πp. \frac{\lVert u-\mathcal G_\theta(a)\rVert}{\lVert u\rVert}\;\gtrsim\;\frac{2}{\pi\sqrt p}. ∥u∥∥u−Gθ​(a)∥​≳πp​2​.

Reaching 1% requires p≈4,000p\approx4{,}000p≈4,000 basis functions — to represent a family that has one degree of freedom. Shocks, fronts, interfaces and traveling waves all behave this way.

1.4 The fix: a nonlinear decoder

A nonlinear decoder can represent the same family with p=1p=1p=1: fθ(y;z)=φ(y−z)f_\theta(y;z)=\varphi(y-z)fθ​(y;z)=φ(y−z) with z=sz=sz=s. The family is a one-dimensional nonlinear manifold embedded in function space; it just isn't close to any low-dimensional linear subspace. NOMAD (Seidman et al., 2022) keeps DeepONet's global code and replaces the linear decoder by a conditional neural field — by concatenation fθ([γ(y);z])f_\theta([\gamma(y);z])fθ​([γ(y);z]) or by modulation (Lecture 19 §4.3). The nnn-width bound no longer applies, and on transport-dominated problems the same code size ppp gives much smaller errors.

The other way around the barrier is to drop the single global code altogether: local conditioning, the subject of the rest of the lecture.

Remember. DeepONet: branch → ppp coefficients, trunk → ppp basis functions, output = their dot product. Global conditioning with a linear decoder. Any linear decoder's mean-squared error is at least the PCA tail ∑k>pλk\sum_{k>p}\lambda_k∑k>p​λk​ of the output distribution; for translated sharp features this decays like p−1p^{-1}p−1, so ppp must be huge. Nonlinear decoders (NOMAD) or local conditioning avoid the barrier.

2. From Green's functions to the neural operator layer (12 min)

2.1 Linear PDEs are integral operators

Consider a linear boundary-value problem, Lu=f\mathcal Lu=fLu=f on DDD with u=0u=0u=0 on ∂D\partial D∂D. Its solution operator f↦uf\mapsto uf↦u is an integral operator with the Green's function GGG as kernel:

u(x)=∫DG(x,x′) f(x′) dx′,LxG(x,x′)=δ(x−x′). u(x) = \int_D G(x,x')\,f(x')\,dx',\qquad \mathcal L_xG(x,x')=\delta(x-x'). u(x)=∫D​G(x,x′)f(x′)dx′,Lx​G(x,x′)=δ(x−x′).

Example: −u′′=f-u''=f−u′′=f on (0,1)(0,1)(0,1) with u(0)=u(1)=0u(0)=u(1)=0u(0)=u(1)=0 has G(x,x′)=min⁡(x,x′)(1−max⁡(x,x′))G(x,x') = \min(x,x')\big(1-\max(x,x')\big)G(x,x′)=min(x,x′)(1−max(x,x′)). For f≡1f\equiv1f≡1, integrating gives u(x)=x(1−x)/2u(x)=x(1-x)/2u(x)=x(1−x)/2, as you can check directly.

Three features of Green's functions guide the architectures that follow:

  1. They are global. G(x,x′)G(x,x')G(x,x′) is generally nonzero for all pairs, so the value at xxx depends on the forcing everywhere. (For the free-space Laplacian in 3D, G=1/(4π∥x−x′∥)G = 1/(4\pi\lVert x-x'\rVert)G=1/(4π∥x−x′∥) decays slowly.)
  2. For translation-invariant operators they are stationary: constant-coefficient problems on unbounded or periodic domains have G(x,x′)=G(x−x′)G(x,x')=G(x-x')G(x,x′)=G(x−x′), so the solution is a convolution.
  3. For variable coefficients they depend on the coefficients. For −(k(x)u′)′=f-(k(x)u')'=f−(k(x)u′)′=f, the Green's function depends on kkk; the map k↦uk\mapsto uk↦u is therefore nonlinear in kkk, even though f↦uf\mapsto uf↦u is linear.

2.2 The neural operator layer

To learn nonlinear operators, Li et al. (2020) and Kovachki et al. (2023) combine learned integral operators with pointwise nonlinearities, by analogy with an MLP layer σ(Wh+b)\sigma(Wh+b)σ(Wh+b):

  vℓ+1(x)=σ(Wℓ vℓ(x)+∫Dκℓ(x,x′) vℓ(x′) dx′+bℓ(x))   \boxed{\;v_{\ell+1}(x) = \sigma\Big(W_\ell\,v_\ell(x) + \int_D\kappa_\ell(x,x')\,v_\ell(x')\,dx' + b_\ell(x)\Big)\;} vℓ+1​(x)=σ(Wℓ​vℓ​(x)+∫D​κℓ​(x,x′)vℓ​(x′)dx′+bℓ​(x))​

The full model is

v0(x)=P(a(x),γ(x))  (lift),v1,…,vL  (kernel layers),u(y)=Q(vL(y))  (project), v_0(x) = P\big(a(x),\gamma(x)\big)\ \ (\text{lift}),\qquad v_1,\dots,v_L\ \ (\text{kernel layers}),\qquad u(y)=Q\big(v_L(y)\big)\ \ (\text{project}), v0​(x)=P(a(x),γ(x))  (lift),v1​,…,vL​  (kernel layers),u(y)=Q(vL​(y))  (project),

with PPP and QQQ applied pointwise. The pointwise term Wℓvℓ(x)W_\ell v_\ell(x)Wℓ​vℓ​(x) is a local, skip-like path; the integral is a nonlocal, Green's-function-like interaction; the nonlinearity and depth let the effective kernel depend on the input, as in point 3. 2.3 Discretization and the CNF view

On data, the integral is replaced by a quadrature over the available samples,

∫Dκ(x,x′) v(x′) dx′  ≈  ∑j=1nwj κ(x,xj) v(xj), \int_D\kappa(x,x')\,v(x')\,dx'\;\approx\;\sum_{j=1}^{n}w_j\,\kappa(x,x_j)\,v(x_j), ∫D​κ(x,x′)v(x′)dx′≈j=1∑n​wj​κ(x,xj​)v(xj​),

and the same parameters apply to any discretization: the layer is defined on functions, and the sample points only determine the quadrature. The output u(y)=Q(vL(y))u(y)=Q(v_L(y))u(y)=Q(vL​(y)) depends on the whole input through LLL integrals, with weights determined by yyy. This is local conditioning: the decoder at yyy sees the latent field at yyy, a query-dependent summary of aaa.

What remains is the hard part: how to parameterize κ\kappaκ, and how to compute the integral for all xxx without O(n2)O(n^2)O(n2) cost. The next three sections give three answers.

Remember. The solution of a linear PDE is ∫G(x,x′)f(x′)dx′\int G(x,x')f(x')dx'∫G(x,x′)f(x′)dx′: global, stationary for constant coefficients, input-dependent for variable ones. A neural operator layer is v↦σ(Wv+∫κv+b)v\mapsto\sigma(Wv+\int\kappa v+b)v↦σ(Wv+∫κv+b), an MLP layer on functions, discretized by quadrature. Each architecture is a choice of kernel and quadrature.

3. Graph neural operators (10 min)

Kernel choice: a small MLP of the two locations (and optionally the input values), restricted to a neighborhood.

vℓ+1(xi)=σ(Wvℓ(xi)+1∣N(i)∣∑xj∈N(i)κϕ(xi,xj,a(xi),a(xj)) vℓ(xj)),N(i)={xj:∥xj−xi∥≤r}. v_{\ell+1}(x_i) = \sigma\Big(W v_\ell(x_i)+\frac{1}{|\mathcal N(i)|}\sum_{x_j\in\mathcal N(i)}\kappa_\phi\big(x_i,x_j,a(x_i),a(x_j)\big)\,v_\ell(x_j)\Big),\qquad \mathcal N(i)=\{x_j:\lVert x_j-x_i\rVert\le r\}. vℓ+1​(xi​)=σ(Wvℓ​(xi​)+∣N(i)∣1​xj​∈N(i)∑​κϕ​(xi​,xj​,a(xi​),a(xj​))vℓ​(xj​)),N(i)={xj​:∥xj​−xi​∥≤r}.

The average is a Monte Carlo estimate of the integral over the ball Br(xi)B_r(x_i)Br​(xi​), and the computation is message passing on the graph that connects points within distance rrr (Li et al., 2020). The kernel network κϕ\kappa_\phiκϕ​ outputs a dv×dvd_v\times d_vdv​×dv​ matrix for each pair.

Strengths. It works on any mesh or point cloud, including irregular geometries and adaptive refinement, and the kernel can depend on the input coefficients, like a variable-coefficient Green's function.

Weaknesses. Cost is O(nkˉ dv2)O(n\bar k\,d_v^2)O(nkˉdv2​) for kˉ\bar kkˉ neighbors per point, and it grows quickly with rrr. A truncated kernel misses the long-range part of the Green's function (§2.1, point 1): reaching distance RRR takes about R/rR/rR/r layers, the same limitation as CNNs. Multipole graph neural operators address this with a hierarchy of graphs at different resolutions, in the spirit of the fast multipole method (Li et al., 2020b).

Its modern role is often as an adapter: map irregular input points to a regular latent grid with a GNO layer, process on the grid with an FNO, and map back to arbitrary output points with another GNO layer (GINO; Li et al., 2023). The final GNO layer is a kernel integral from grid nodes to the query yyy — local conditioning, made explicit.

4. Fourier neural operators (13 min)

4.1 Construction

Kernel choice: stationary, κ(x,x′)=κ(x−x′)\kappa(x,x')=\kappa(x-x')κ(x,x′)=κ(x−x′), motivated by §2.1 point 2. The integral becomes a convolution, which the convolution theorem turns into a product in Fourier space:

∫Dκ(x−x′) v(x′) dx′=F−1(κ^(k) v^(k))(x). \int_D\kappa(x-x')\,v(x')\,dx' = \mathcal F^{-1}\big(\hat\kappa(k)\,\hat v(k)\big)(x). ∫D​κ(x−x′)v(x′)dx′=F−1(κ^(k)v^(k))(x).

The FNO (Li et al., 2021) parameterizes κ^\hat\kappaκ^ directly: a learned complex matrix Rℓ(k)∈Cdv×dvR_\ell(k)\in\mathbb{C}^{d_v\times d_v}Rℓ​(k)∈Cdv​×dv​ for each wavenumber up to a cutoff kmax⁡k_{\max}kmax​ per dimension, and zero beyond:

vℓ+1(x)=σ(Wℓvℓ(x)+F−1[ Rℓ(k) v^ℓ(k) 1∣k∣≤kmax⁡](x)). v_{\ell+1}(x) = \sigma\Big(W_\ell v_\ell(x) + \mathcal F^{-1}\big[\,R_\ell(k)\,\hat v_\ell(k)\,\mathbf 1_{|k|\le k_{\max}}\big](x)\Big). vℓ+1​(x)=σ(Wℓ​vℓ​(x)+F−1[Rℓ​(k)v^ℓ​(k)1∣k∣≤kmax​​](x)).

On a regular grid of nnn points: FFT each channel, multiply the retained modes by Rℓ(k)R_\ell(k)Rℓ​(k) (mixing channels), zero the rest, inverse FFT, add the pointwise path WℓvℓW_\ell v_\ellWℓ​vℓ​, apply σ\sigmaσ. A typical model uses lifting, four Fourier layers and projection.

4.2 Properties

  • Global in one layer. Every output point depends on every input point, like a Green's function. Compare GNOs and CNNs, which need depth to reach far.
  • Cost O(nlog⁡n)O(n\log n)O(nlogn) per channel for the FFTs, plus O(n dv2)O(n\,d_v^2)O(ndv2​) for the pointwise path.
  • Parameters O(kmax⁡d dv2)O(k_{\max}^{d}\,d_v^2)O(kmaxd​dv2​) per layer, independent of the grid.
  • Resolution transfer. A CNN stencil is tied to grid spacing (Lecture 14 §7). FNO weights are tied to physical wavenumbers, so the same weights define the same operator on any grid fine enough to resolve kmax⁡k_{\max}kmax​.
  • Spectral regularization. Truncating at kmax⁡k_{\max}kmax​ removes high-frequency content from the kernel. The nonlinearity and the pointwise path reintroduce high frequencies in the output, so the model is not band-limited overall — but the global interactions are.

4.4 The CNF view

The FNO outputs a latent field on the grid, and the prediction at yyy is Q(vL(y))Q(v_L(y))Q(vL​(y)): local conditioning. At grid points this is direct. At arbitrary yyy, the last latent field can be evaluated by its truncated Fourier series (spectral interpolation) or by a cross-attention or GNO decoder from the grid, which makes the conditional-neural-field decoder explicit.

Remember. FNO: stationary kernel, applied by FFT, with learned complex weights on the lowest kmax⁡k_{\max}kmax​ modes. Global in one layer, O(nlog⁡n)O(n\log n)O(nlogn), parameters independent of resolution, weights tied to physical frequencies. Needs regular grids and padding for non-periodic domains; test resolution transfer rather than assume it.

5. Attention-based neural operators (18 min)

5.1 Attention is an input-dependent kernel integral

5.2 The template: encoder, latent tokens, cross-attention decoder

Most attention-based neural operators share one structure, which is a conditional neural field with local conditioning.

Encoder. Turn the input samples into tokens, hj=P a(xj)+γ(xj)Wposh_j = P\,a(x_j)+\gamma(x_j)W_{\text{pos}}hj​=Pa(xj​)+γ(xj​)Wpos​, with Fourier features of the physical coordinates as positional encoding (Lecture 17 §1.4). Then apply transformer blocks: self-attention, which is the input-dependent integral of §5.1, plus per-token MLPs, residuals and LayerNorm.

Decoder. For any query yyy, embed it, e(y)=γ(y)Wee(y)=\gamma(y)W_ee(y)=γ(y)We​, and cross-attend to the encoder's tokens Z={zm}Z=\{z_m\}Z={zm​}:

c(y)=∑msoftmax⁡m((e(y)WQ)⊤zmWKdk) zmWV,Gθ(a)(y)=gθ(e(y)+c(y)). c(y) = \sum_{m}\operatorname{softmax}_m\Big(\frac{(e(y)W_Q)^\top z_mW_K}{\sqrt{d_k}}\Big)\,z_mW_V,\qquad \mathcal G_\theta(a)(y) = g_\theta\big(e(y)+c(y)\big). c(y)=m∑​softmaxm​(dk​​(e(y)WQ​)⊤zm​WK​​)zm​WV​,Gθ​(a)(y)=gθ​(e(y)+c(y)).

This is the local-conditioning formula of §0.3, with attention as the kernel: each query computes its own weights over the encoded input. Queries do not attend to one another, so the output can be evaluated at any points, any number of them, in parallel — including a random subset at each training step (Lecture 19 §0.3). It is Bahdanau attention (Lecture 16 §1) with spatial coordinates as the queries.

def operator(xs, a_vals, ys, P):                   # input samples -> any query points
    h = a_vals @ P.W_in + fourier_features(xs, P.B) @ P.W_pos     # (n, d) tokens
    z = encoder(h, P.enc)                                          # (M, d) tokens
    e = fourier_features(ys, P.Bq) @ P.W_q                         # (m, d) queries
    for p in P.dec_blocks:                                         # queries are independent
        e = e + cross_attention(q=layer_norm(e), kv=z, p=p)       # local conditioning
        e = e + mlp(layer_norm(e), p)
    return e @ P.W_out                                             # (m, d_u) = G(a)(ys)

5.3 Making it affordable

Self-attention over nnn input points costs O(n2d)O(n^2d)O(n2d): about 2.7×10112.7\times10^{11}2.7×1011 operations per layer for a 256×256256\times256256×256 field with d=64d=64d=64. Four ideas are widely used, often combined.

Idea How Cost Example
Patches On regular grids, group P×PP\times PP×P points into one token (as in ViT) O((n/P2)2d)O\big((n/P^2)^2d\big)O((n/P2)2d) CViT (Wang et al., 2024)
Latent tokens M≪nM\ll nM≪n learned queries cross-attend to the input, then self-attend among themselves O(nMd+M2d)O(nMd+M^2d)O(nMd+M2d) Perceiver IO (Jaegle et al., 2022)

Linear (Galerkin-type) attention Drop the softmax and reassociate: Q(K⊤V)/nQ(K^\top V)/nQ(K⊤V)/n instead of (QK⊤)V(QK^\top)V(QK⊤)V O(nd2)O(nd^2)O(nd2) Galerkin transformer (Cao, 2021)

The last row has a clean interpretation. Without the softmax, (K⊤V)/n≈∫k(x′)⊤v(x′) dx′(K^\top V)/n\approx\int k(x')^\top v(x')\,dx'(K⊤V)/n≈∫k(x′)⊤v(x′)dx′ is a d×dd\times dd×d matrix of inner products between learned functions, and multiplying by QQQ projects onto a learned basis — a Petrov–Galerkin projection. It is a rank-ddd kernel, κ(x,x′)=q(x)⊤k(x′)\kappa(x,x')=q(x)^\top k(x')κ(x,x′)=q(x)⊤k(x′): linear-cost, but low-rank, much like DeepONet's kernel (Lecture 19 §6.4). Speed is traded for the expressiveness of a full kernel.

5.4 Two examples of the template

  • Grids in, any points out. A vision-transformer encoder on patches of a gridded input, followed by a cross-attention decoder at continuous query coordinates (CViT; Wang et al., 2024). The patch tokens are the conditioning set ZZZ.
  • Irregular samples in, any points out. Tokens per input point or per learned latent, with a cross-attention decoder (OFormer, Li et al., 2023c; GNOT, Hao et al., 2023, which also handles multiple input functions). Attention-based decoders over output queries also appear in LOCA (Kissas et al., 2022), which couples the attention weights of nearby query points through a kernel.

Whichever variant: if the decoder averaged all tokens into one vector before reading them, it would become global conditioning, and the bottleneck of §1 would return. What makes these models expressive is that each query selects what it reads.

Remember. Attention is a kernel integral whose kernel is computed from the input at every layer: global, mesh-free, and input-dependent. Transformer NOs encode input samples into tokens and decode with cross-attention from Fourier-embedded query coordinates — a conditional neural field with local conditioning. Patches, latent tokens, slices and linear attention reduce the O(n2)O(n^2)O(n2) cost; linear attention does so by making the kernel low-rank.

6.2 How to choose

If your data look like… Start with Because
Regular grid, roughly periodic or smooth boundaries, moderate resolution FNO global, cheap, a strong baseline
Smooth outputs with fast-decaying PCA spectrum, fixed sensors DeepONet / POD-DeepONet simplest and cheapest; the nnn-width barrier will not bite
Moving fronts, shocks, transport-dominated outputs nonlinear decoder (NOMAD) or local conditioning the PCA spectrum decays slowly (§1.3)
Irregular meshes or complex geometry GNO/GINO, or a transformer NO with slices or latents mesh-free kernels
Scattered sensors in, arbitrary query points out transformer NO with a cross-attention decoder handles both sides natively
Small datasets the simplest model that fits, plus strong baselines inductive bias beats flexibility with little data (Lecture 17 §6)

Check the spectrum first. Before training anything, compute the PCA spectrum of your training outputs (Lecture 4). If ∑k>pλk\sum_{k>p}\lambda_k∑k>p​λk​ is already small for modest ppp, a linear decoder suffices and anything fancier must justify itself. If it decays slowly, no linear decoder will do well, whatever its encoder.

Evaluate like an experimentalist (Lecture 13 §8, Lecture 19 §8): report relative L2L^2L2 error with mean ±\pm± std over seeds; test at resolutions and on input distributions you did not train on; and compare not only against other networks but against the cost of running the solver, including the cost of generating the training data. A neural operator pays off only after it has been queried many times.

Quiz-eligible facts

  1. Global conditioning passes one code zzz to every query; local conditioning gives each query its own kernel-weighted integral of the input.
  2. DeepONet: Gθ(a)(y)=∑k=1pBk(a(x1),…,a(xm))Tk(y)+b0\mathcal G_\theta(a)(y)=\sum_{k=1}^pB_k(a(x_1),\dots,a(x_m))T_k(y)+b_0Gθ​(a)(y)=∑k=1p​Bk​(a(x1​),…,a(xm​))Tk​(y)+b0​ — global conditioning, linear decoder; universal (Chen & Chen, 1995), but fixed input sensors.

  4. Translated profiles have a stationary covariance, so their PCA basis is Fourier modes with eigenvalues ∣φ^(k)∣2|\hat\varphi(k)|^2∣φ^​(k)∣2; for a discontinuous profile the relative error decays only like p−1/2p^{-1/2}p−1/2.
  5. A nonlinear decoder (NOMAD) can represent a one-parameter family of translations with p=1p=1p=1.
  6. Linear PDE solutions are u(x)=∫G(x,x′)f(x′)dx′u(x)=\int G(x,x')f(x')dx'u(x)=∫G(x,x′)f(x′)dx′; Green's functions are global, stationary for constant coefficients, input-dependent for variable coefficients.

P4. An FNO trained on 64×6464\times6464×64 grids with kmax⁡=12k_{\max}=12kmax​=12 is applied to 256×256256\times256256×256 grids. Which parameters change, and why might the error still increase?

Answer. None: the spectral weights are tied to wavenumbers, not grid points. The error can still change because pointwise nonlinearities generate frequencies above what the training grid could represent; at training resolution these aliased onto lower modes, and the learned weights compensated for that aliasing, which no longer happens at the finer resolution.
