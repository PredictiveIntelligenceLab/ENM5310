1. Where we are: Bayesian linear regression in three steps

Every method in this course can be described in three steps.

Step 1 — Model. Write down a probabilistic model of how the data were generated: what is observed, what is unknown, and what distributions connect them.

Step 2 — Training. Use the observed data to determine the unknowns.

Step 3 — Inference. Use the trained model to make predictions, with uncertainty, at new inputs.

Here is Bayesian linear regression from Lecture 7 in that form.

2. A failure: confidently wrong far from the data

Take a natural basis for smooth one-dimensional regression: radial basis functions (RBFs), Gaussian bumps of width λ\lambdaλ centered at points c1,…,cDc_1,\dots,c_Dc1​,…,cD​,

ϕd(x)=exp⁡ ⁣(−(x−cd)22λ2).\phi_d(x) = \exp\!\left(-\frac{(x-c_d)^2}{2\lambda^2}\right).ϕd​(x)=exp(−2λ2(x−cd​)2​).

Place the centers on a grid covering the training inputs, say [−1,1][-1,1][−1,1], fit Bayesian linear regression, and plot the predictive distribution over [−5,5][-5,5][−5,5].

Inside [−1,1][-1,1][−1,1] the fit looks excellent. The mean follows the data, and the epistemic band is narrow near observations and wider between them.

Now move to x⋆=5x^\star = 5x⋆=5. Every basis function is centered far away, so every entry of ϕ(x⋆)\phi(x^\star)ϕ(x⋆) is essentially zero. Then

mN⊤ϕ⋆≈0andϕ⋆⊤SNϕ⋆≈0.m_N^\top\phi^\star\approx0 \qquad\text{and}\qquad \phi^{\star\top}S_N\phi^\star\approx0 .mN⊤​ϕ⋆≈0andϕ⋆⊤SN​ϕ⋆≈0.

The mean falls to zero. So does the epistemic variance. The only uncertainty left is the noise σ2\sigma^2σ2 — the same width the model reports in the middle of the densest data. The model is claiming that the function equals zero at x=5x = 5x=5, and that it is as sure of this as of anything it has seen.

Nothing went wrong in the calculation. The formulas were applied correctly. So the right question is not "where is the bug in the posterior?" but:

What did we assume about the function before we saw any data?

A prior over weights does not answer this directly. We need to translate it into a statement about functions.

3. From weights to functions

3.1 A prior on weights is a prior on functions

Pick any inputs x1,…,xMx_1,\dots,x_Mx1​,…,xM​ and collect the function values into a vector f=(f(x1),…,f(xM))⊤f = (f(x_1),\dots,f(x_M))^\topf=(f(x1​),…,f(xM​))⊤. With f(x)=w⊤ϕ(x)f(x) = w^\top\phi(x)f(x)=w⊤ϕ(x) this is f=Φwf = \Phi wf=Φw. A linear function of a Gaussian is Gaussian, so

E[f]=0,Cov⁡[f]=Φ (τ2I) Φ⊤=τ2ΦΦ⊤.\mathbb{E}[f] = 0, \qquad \operatorname{Cov}[f] = \Phi\,(\tau^2I)\,\Phi^\top = \tau^2\Phi\Phi^\top .E[f]=0,Cov[f]=Φ(τ2I)Φ⊤=τ2ΦΦ⊤.

Reading off the individual entries:

 Cov⁡[f(x),f(x′)]=τ2 ϕ(x)⊤ϕ(x′),Var⁡[f(x)]=τ2 ∥ϕ(x)∥2. \boxed{\ \operatorname{Cov}\big[f(x),f(x')\big] = \tau^2\,\phi(x)^\top\phi(x'), \qquad \operatorname{Var}\big[f(x)\big] = \tau^2\,\|\phi(x)\|^2 .\ } Cov[f(x),f(x′)]=τ2ϕ(x)⊤ϕ(x′),Var[f(x)]=τ2∥ϕ(x)∥2. ​

The prior on www is now a direct statement about the function: how much its value at each input varies, and how its values at different inputs move together.

3.2 The failure, diagnosed

For the RBF basis, ∥ϕ(x)∥2=∑dexp⁡(−(x−cd)2/λ2)\|\phi(x)\|^2 = \sum_d\exp\big(-(x-c_d)^2/\lambda^2\big)∥ϕ(x)∥2=∑d​exp(−(x−cd​)2/λ2), which goes to zero far from every center. So:

Before seeing any data, the prior already said that f(x)f(x)f(x) is zero, with near-certainty, far from the centers.

Data could not have fixed this. Recall the conditioning formula from Lecture 2: for jointly Gaussian (z1,z2)(z_1,z_2)(z1​,z2​),

Cov⁡[z1∣z2]=Σ11−Σ12Σ22−1Σ21.\operatorname{Cov}[z_1\mid z_2] = \Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}.Cov[z1​∣z2​]=Σ11​−Σ12​Σ22−1​Σ21​.

The subtracted term is always positive semi-definite, so the conditional variance is never larger than the unconditional one.

Conditioning never increases variance. Data can only remove uncertainty that the prior contained. Where the prior contained none, the posterior has none either.

The failure in §2 was a failure of the prior. It is hard to see in weight space and obvious in function space. That is the reason to think in terms of functions from here on: it is the view in which our real assumptions — how the function should behave, and how unsure we are, at each input — are written down explicitly.

4. From features to kernels

4.1 Only inner products matter

Look at §3.1 again. The prior over function values depends on the features only through the inner product ϕ(x)⊤ϕ(x′)\phi(x)^\top\phi(x')ϕ(x)⊤ϕ(x′). The individual features never appear alone. (We will see in §7 that the same is true of the predictions.) That suggests skipping the features and specifying the inner product directly.

Kernel. A function k(x,x′)k(x,x')k(x,x′) giving the prior covariance between function values: k(x,x′)=Cov⁡[f(x),f(x′)]k(x,x') = \operatorname{Cov}[f(x),f(x')]k(x,x′)=Cov[f(x),f(x′)]. From features, k(x,x′)=τ2ϕ(x)⊤ϕ(x′)k(x,x') = \tau^2\phi(x)^\top\phi(x')k(x,x′)=τ2ϕ(x)⊤ϕ(x′).

Gram matrix. For inputs x1,…,xMx_1,\dots,x_Mx1​,…,xM​, the matrix KKK with entries Kij=k(xi,xj)K_{ij} = k(x_i,x_j)Kij​=k(xi​,xj​).

Not every function of two inputs can be a kernel. Every Gram matrix must be a valid covariance matrix:

Valid kernel. kkk is symmetric, and every Gram matrix it produces is positive semi-definite.

Any kernel built from features is valid, and §4.4 shows the converse: every valid kernel comes from some feature map. Sums, products, and positive multiples of valid kernels are also valid, which is how kernels get combined.

4.2 The fix, by design

The failure came from the prior variance k(x,x)=τ2∥ϕ(x)∥2k(x,x) = \tau^2\|\phi(x)\|^2k(x,x)=τ2∥ϕ(x)∥2 falling to zero. So ask for a kernel where that cannot happen:

Stationary kernel. k(x,x′)k(x,x')k(x,x′) depends only on the difference x−x′x-x'x−x′. Then the prior variance k(x,x)k(x,x)k(x,x) is the same at every input, so it never collapses — and by §3.2, neither does the posterior's.

Is there a stationary kernel that corresponds to a sensible feature model? Yes, and it is the RBF model that just failed.

4.3 ★ Infinitely many features: the squared-exponential kernel

The RBF model failed because its bumps covered only [−1,1][-1,1][−1,1]. The obvious fix is to place bumps everywhere. In weight space that is impossible — infinitely many weights. But the kernel only needs the sum ∑dϕd(x)ϕd(x′)\sum_d\phi_d(x)\phi_d(x')∑d​ϕd​(x)ϕd​(x′), and that sum has a closed form.

Place centers cd=dΔc_d = d\Deltacd​=dΔ on a grid of spacing Δ\DeltaΔ covering the whole real line. The kernel is

k(x,x′)=τ2∑dexp⁡ ⁣(−(x−cd)22λ2)exp⁡ ⁣(−(x′−cd)22λ2).k(x,x') = \tau^2\sum_d\exp\!\left(-\frac{(x-c_d)^2}{2\lambda^2}\right)\exp\!\left(-\frac{(x'-c_d)^2}{2\lambda^2}\right).k(x,x′)=τ2d∑​exp(−2λ2(x−cd​)2​)exp(−2λ2(x′−cd​)2​).

Combine the exponents. With xˉ=(x+x′)/2\bar x = (x+x')/2xˉ=(x+x′)/2, one checks by expanding that (x−c)2+(x′−c)2=2(c−xˉ)2+12(x−x′)2(x-c)^2+(x'-c)^2 = 2(c-\bar x)^2+\tfrac12(x-x')^2(x−c)2+(x′−c)2=2(c−xˉ)2+21​(x−x′)2. So each term is

exp⁡ ⁣(−(x−x′)24λ2)exp⁡ ⁣(−(cd−xˉ)2λ2),\exp\!\left(-\frac{(x-x')^2}{4\lambda^2}\right)\exp\!\left(-\frac{(c_d-\bar x)^2}{\lambda^2}\right),exp(−4λ2(x−x′)2​)exp(−λ2(cd​−xˉ)2​),

and the first factor comes out of the sum.

Turn the sum into an integral. For a fine grid, Δ≪λ\Delta\ll\lambdaΔ≪λ, the remaining sum is approximately 1Δ∫exp⁡(−(c−xˉ)2/λ2)dc=λπ/Δ\frac1\Delta\int\exp\big(-(c-\bar x)^2/\lambda^2\big)dc = \lambda\sqrt\pi/\DeltaΔ1​∫exp(−(c−xˉ)2/λ2)dc=λπ​/Δ.

Keep the variance finite. As Δ→0\Delta\to0Δ→0 this would blow up, so each weight's prior variance must shrink as the grid gets finer: τ2=σf2Δ/(λπ)\tau^2 = \sigma_f^2\Delta/(\lambda\sqrt\pi)τ2=σf2​Δ/(λπ​). Writing ℓ=2λ\ell = \sqrt2\lambdaℓ=2​λ, the limit is

 kSE(x,x′)=σf2exp⁡ ⁣(−(x−x′)22ℓ2). \boxed{\ k_{\mathrm{SE}}(x,x') = \sigma_f^2\exp\!\left(-\frac{(x-x')^2}{2\ell^2}\right).\ } kSE​(x,x′)=σf2​exp(−2ℓ2(x−x′)2​). ​

This is the squared-exponential kernel. Three things to notice:

  • It is stationary. k(x,x)=σf2k(x,x) = \sigma_f^2k(x,x)=σf2​ everywhere. The prior is never certain anywhere.
  • It is the failed model, completed. Nothing new was assumed — just more of the same basis functions, everywhere.
  • The cost moved. Weight space would need an infinite matrix. As §7 shows, the kernel view needs only an N×NN\times NN×N matrix, however many features there are.

4.4 ★ Features and kernels determine each other: Mercer's theorem

So far we have gone in one direction. Given features, the kernel is their inner product (absorbing τ2\tau^2τ2 into the features):

k(x,x′)=∑dϕd(x) ϕd(x′).k(x,x') = \sum_d\phi_d(x)\,\phi_d(x').k(x,x′)=d∑​ϕd​(x)ϕd​(x′).

This always produces a valid kernel. The reverse direction — given a kernel, find features — is Mercer's theorem, and it is easiest to see first for matrices.

The matrix version, which you already know. A Gram matrix KKK is symmetric and positive semi-definite, so it has an eigendecomposition with non-negative eigenvalues:

K=∑jλj ujuj⊤⟹Knm=∑j(λj ujn)(λj ujm).K = \sum_j\lambda_j\,u_ju_j^\top \qquad\Longrightarrow\qquad K_{nm} = \sum_j\big(\sqrt{\lambda_j}\,u_{jn}\big)\big(\sqrt{\lambda_j}\,u_{jm}\big).K=j∑​λj​uj​uj⊤​⟹Knm​=j∑​(λj​​ujn​)(λj​​ujm​).

Read the right-hand side: input xnx_nxn​ has a feature vector with components λj ujn\sqrt{\lambda_j}\,u_{jn}λj​​ujn​, and KKK is exactly the matrix of inner products of these feature vectors. Every valid Gram matrix is secretly a feature model.

The function version. Mercer's theorem says the same thing for the kernel itself, with eigenvectors replaced by eigenfunctions and the matrix product replaced by an integral.

Mercer's theorem. Let kkk be a continuous valid kernel on a bounded input domain, with inputs weighted by a density p(x)p(x)p(x). Then there are orthonormal functions ψ1,ψ2,…\psi_1,\psi_2,\dotsψ1​,ψ2​,… and numbers λ1≥λ2≥⋯≥0\lambda_1\ge\lambda_2\ge\dots\ge0λ1​≥λ2​≥⋯≥0 satisfying

∫k(x,x′) ψj(x′) p(x′) dx′=λj ψj(x),\int k(x,x')\,\psi_j(x')\,p(x')\,dx' = \lambda_j\,\psi_j(x),∫k(x,x′)ψj​(x′)p(x′)dx′=λj​ψj​(x),

such that

k(x,x′)=∑j=1∞λj ψj(x) ψj(x′).k(x,x') = \sum_{j=1}^\infty\lambda_j\,\psi_j(x)\,\psi_j(x').k(x,x′)=j=1∑∞​λj​ψj​(x)ψj​(x′).

So every valid kernel is an inner product of features, ϕj(x)=λj ψj(x)\phi_j(x) = \sqrt{\lambda_j}\,\psi_j(x)ϕj​(x)=λj​​ψj​(x) — possibly infinitely many of them. The two directions together:

features ϕ⏟weight space →  inner product   kernel k⏟function space →  Mercer eigendecomposition   features λj ψj.\underbrace{\text{features }\phi}_{\text{weight space}}\ \xrightarrow{\ \ \text{inner product}\ \ }\ \underbrace{\text{kernel }k}_{\text{function space}}\ \xrightarrow{\ \ \text{Mercer eigendecomposition}\ \ }\ \text{features }\sqrt{\lambda_j}\,\psi_j .weight spacefeatures ϕ​​   inner product  ​ function spacekernel k​​   Mercer eigendecomposition  ​ features λj​​ψj​.

Three consequences.

Every GP is Bayesian linear regression, always. The random function

f(x)=∑jwjλj ψj(x),wj∼N(0,1) independent,f(x) = \sum_j w_j\sqrt{\lambda_j}\,\psi_j(x), \qquad w_j\sim\mathcal{N}(0,1)\ \text{independent},f(x)=j∑​wj​λj​​ψj​(x),wj​∼N(0,1) independent,

has covariance exactly kkk. The weight-space and function-space views of §3 are not just related for special kernels; they are equivalent for every valid kernel.

The eigenvalues reveal the assumptions. λj\lambda_jλj​ is how much prior variance the kernel puts on its jjj-th feature, and for the stationary kernels in this lecture, later features oscillate faster. For the squared-exponential the λj\lambda_jλj​ decay extremely fast, so almost all prior variance sits on a few smooth features — hence very smooth samples. For Matérn kernels they decay more slowly, leaving more weight on oscillatory features — hence rougher samples. The table in §5.3 is really a statement about how fast the eigenvalues decay.

Truncation gives a cheaper model. Keeping only the first MMM features, k(x,x′)≈∑j≤Mλjψj(x)ψj(x′)k(x,x')\approx\sum_{j\le M}\lambda_j\psi_j(x)\psi_j(x')k(x,x′)≈∑j≤M​λj​ψj​(x)ψj​(x′), turns the GP back into Bayesian linear regression with MMM features, whose training cost is O(NM2+M3)O(NM^2+M^3)O(NM2+M3) instead of O(N3)O(N^3)O(N3). In practice the ψj\psi_jψj​ are approximated from the eigenvectors of a Gram matrix on a sample of inputs — the matrix version above — and this is one of the main routes to scalable GPs.

One caution: the feature map is not unique. Replacing ϕ\phiϕ by QϕQ\phiQϕ for any orthogonal matrix QQQ leaves every inner product, and so the kernel, unchanged. The kernel is the object the model actually depends on — one more reason to specify it directly.

5. Step 1 — The model: a Gaussian process prior

5.1 What a Gaussian process is

Gaussian process. A random function fff such that, for any finite set of inputs, the vector of function values is jointly Gaussian. It is specified by a mean function m(x)m(x)m(x) and a kernel k(x,x′)k(x,x')k(x,x′), and we write f∼GP(m,k)f\sim\mathcal{GP}(m,k)f∼GP(m,k).

In practice you never handle a whole function. You only evaluate it at finitely many inputs, and there it is an ordinary multivariate Gaussian: (f(x1),…,f(xM))∼N(0,K)\big(f(x_1),\dots,f(x_M)\big)\sim\mathcal{N}(0,K)(f(x1​),…,f(xM​))∼N(0,K) when m=0m = 0m=0. Everything in this lecture is Lecture 2's Gaussian algebra applied to such a vector. We use m≡0m\equiv0m≡0 throughout.

5.2 The model

 Step 1:f∼GP(0,kθ),yn=f(xn)+ϵn,ϵn∼N(0,σ2). \boxed{\ \textbf{Step 1:}\qquad f\sim\mathcal{GP}(0,k_\theta), \qquad y_n = f(x_n)+\epsilon_n, \qquad \epsilon_n\sim\mathcal{N}(0,\sigma^2).\ } Step 1:f∼GP(0,kθ​),yn​=f(xn​)+ϵn​,ϵn​∼N(0,σ2). ​

At the training inputs this says two simple things. Write f=(f(x1),…,f(xN))⊤f = (f(x_1),\dots,f(x_N))^\topf=(f(x1​),…,f(xN​))⊤. Then

prior:f∼N(0,Kθ),likelihood:y∣f∼N(f,σ2I).\text{prior:}\quad f\sim\mathcal{N}(0,K_\theta), \qquad\qquad \text{likelihood:}\quad y\mid f\sim\mathcal{N}(f,\sigma^2I).prior:f∼N(0,Kθ​),likelihood:y∣f∼N(f,σ2I).

The unknowns are the function fff and the hyperparameters θ=(σf2,ℓ,σ2)\theta = (\sigma_f^2,\ell,\sigma^2)θ=(σf2​,ℓ,σ2). There are no weights. The function itself plays the role that www played in Lecture 7.

5.3 Choosing a kernel is choosing assumptions

Write r=∣x−x′∣r = |x-x'|r=∣x−x′∣. Each kernel below has an amplitude σf2\sigma_f^2σf2​ — how large the function typically is — and a length scale ℓ\ellℓ — roughly, how far you must move before the function's value changes substantially.

Three remarks.

Always look at prior samples before fitting. Build KKK on a fine grid of inputs, factor it as K=LL⊤K = LL^\topK=LL⊤ (Cholesky), and draw f=Lzf = Lzf=Lz with z∼N(0,I)z\sim\mathcal{N}(0,I)z∼N(0,I). A handful of draws shows exactly what the kernel assumes.

Smoothness is an assumption. The squared-exponential assumes the function is infinitely smooth, which is stronger than most physical quantities justify. Matérn-5/2 is a better default for physical data.

The linear kernel recovers Lecture 7 exactly. A GP with k=τ2ϕ⊤ϕ′k = \tau^2\phi^\top\phi'k=τ2ϕ⊤ϕ′ makes the same predictions as Bayesian linear regression with basis ϕ\phiϕ. GPs do not replace what we did; they contain it.

6. Step 2 — Training: fitting the hyperparameters

6.1 What is there to learn?

Two kinds of unknowns came out of Step 1, and they are treated differently.

  • The function fff. Infinitely many values, and the data tells us about only a few of them. Following Lecture 7, we keep a full distribution over it and never commit to a single function. That happens in Step 3.
  • The hyperparameters θ\thetaθ. A handful of numbers — three, here — describing the kind of function. The data typically pins these down well, so we pick single best values, in the spirit of Lecture 4.

So Step 2 is: find good values of θ\thetaθ. The natural first idea is the one from Lecture 4 — maximize the likelihood.

6.2 Why not maximize the likelihood over everything?

Try maximizing the likelihood jointly over the function and the noise:

p(y∣f,σ2)=∏n=1NN(yn ∣ f(xn), σ2).p(y\mid f,\sigma^2) = \prod_{n=1}^N\mathcal{N}\big(y_n\,\big|\,f(x_n),\,\sigma^2\big).p(y∣f,σ2)=n=1∏N​N(yn​∣∣​f(xn​),σ2).

The best function is obvious: set f(xn)=ynf(x_n) = y_nf(xn​)=yn​ at every training input, so every residual is zero. The likelihood is then

p(y∣f,σ2)=(2πσ2)−N/2,p(y\mid f,\sigma^2) = (2\pi\sigma^2)^{-N/2},p(y∣f,σ2)=(2πσ2)−N/2,

which grows without bound as σ2→0\sigma^2\to0σ2→0. The maximum does not exist.

This is the collapsing-variance failure from Lecture 5: the model "explains" the data by memorizing it and declaring there is no noise at all. The function is simply too flexible to be chosen by maximization. Any hyperparameters fitted this way are meaningless.

6.3 The fix: average over the function instead of maximizing over it

Instead of asking

How well does the best function explain the data?

ask

How well does a typical function from my prior explain the data, on average?

Mathematically, average the likelihood over the prior on fff:

 p(y∣θ)=∫p(y∣f,σ2)  p(f∣θ)  df. \boxed{\ p(y\mid\theta) = \int p(y\mid f,\sigma^2)\;p(f\mid\theta)\;df .\ } p(y∣θ)=∫p(y∣f,σ2)p(f∣θ)df. ​

This is the marginal likelihood. "Marginal" because fff has been integrated out — marginalized — rather than optimized.

Two things make it the right objective:

  • It cannot memorize. A single perfect-fitting function no longer wins, because it is just one function among all those the prior allows, and it is weighted by how plausible the prior finds it.
  • It is an ordinary likelihood. It is the probability of the observed data as a function of the remaining unknowns, θ\thetaθ — exactly the kind of object Lecture 4 maximized. So maximizing it is simply maximum likelihood for the hyperparameters. This is called type-II maximum likelihood or empirical Bayes.

In short: Bayes for the function, maximum likelihood for the hyperparameters.

6.4 Computing it

The integral looks daunting, but Step 1 makes it easy. At the training inputs,

y=f+ϵ,f∼N(0,Kθ),ϵ∼N(0,σ2I),f and ϵ independent.y = f+\epsilon, \qquad f\sim\mathcal{N}(0,K_\theta), \qquad \epsilon\sim\mathcal{N}(0,\sigma^2I), \qquad f\text{ and }\epsilon\text{ independent}.y=f+ϵ,f∼N(0,Kθ​),ϵ∼N(0,σ2I),f and ϵ independent.

A sum of independent Gaussians is Gaussian, with the covariances added. So without evaluating any integral,

 p(y∣θ)=N(y ∣ 0, Cθ),Cθ=Kθ+σ2I. \boxed{\ p(y\mid\theta) = \mathcal{N}\big(y\,\big|\,0,\ C_\theta\big), \qquad C_\theta = K_\theta+\sigma^2I .\ } p(y∣θ)=N(y∣∣​0, Cθ​),Cθ​=Kθ​+σ2I. ​

Taking logs,

log⁡p(y∣θ)=−12 y⊤Cθ−1y⏟data fit − 12log⁡∣Cθ∣⏟complexity penalty − N2log⁡2π.\log p(y\mid\theta) = \underbrace{-\tfrac12\,y^\top C_\theta^{-1}y}_{\text{data fit}}\ \underbrace{-\ \tfrac12\log\big|C_\theta\big|}_{\text{complexity penalty}}\ -\ \tfrac N2\log2\pi .logp(y∣θ)=data fit−21​y⊤Cθ−1​y​​ complexity penalty− 21​log∣∣​Cθ​∣∣​​​ − 2N​log2π.

6.5 Why this picks sensible hyperparameters

Return to the question in §6.3 — how well does a typical prior function explain the data? — and try it for three length scales.

  • Length scale too short. Prior functions wiggle wildly. Almost any particular draw wiggles the wrong way at most data points. On average, poor fit.
  • Length scale too long. Prior functions are nearly flat. If the data vary, almost every draw misses them. On average, poor fit.
  • Length scale about right. Many prior draws follow the general shape of the data. On average, good fit.

The marginal likelihood is highest in the third case. It prefers the simplest model that still explains the data — Occam's razor — without anyone adding a penalty for complexity. The penalty comes from the averaging.

The same idea explains the two terms. p(y∣θ)p(y\mid\theta)p(y∣θ) is a probability distribution over all possible datasets, so it must add up to one. A very flexible model can produce many different datasets, so it spreads its probability thinly and gives only a little to the one we observed. That is the −12log⁡∣Cθ∣-\frac12\log|C_\theta|−21​log∣Cθ​∣ term, which is large and negative when the model is flexible. A rigid model concentrates its probability on a few smooth datasets; if ours is not among them, the data-fit term −12y⊤Cθ−1y-\frac12y^\top C_\theta^{-1}y−21​y⊤Cθ−1​y is large and negative. The maximum balances the two.

6.6 The same recipe answers loose end (a)

Lecture 7 left σ2\sigma^2σ2 and τ2\tau^2τ2 unexplained. Bayesian linear regression is a GP with kernel k=τ2ϕ⊤ϕ′k = \tau^2\phi^\top\phi'k=τ2ϕ⊤ϕ′, whose Gram matrix is K=τ2ΦΦ⊤K = \tau^2\Phi\Phi^\topK=τ2ΦΦ⊤. So its marginal likelihood is

p(y∣σ2,τ2)=N(y ∣ 0, τ2ΦΦ⊤+σ2I),p(y\mid\sigma^2,\tau^2) = \mathcal{N}\big(y\,\big|\,0,\ \tau^2\Phi\Phi^\top+\sigma^2I\big),p(y∣σ2,τ2)=N(y∣∣​0, τ2ΦΦ⊤+σ2I),

and maximizing it over (σ2,τ2)(\sigma^2,\tau^2)(σ2,τ2) chooses them. Since the ridge penalty is λ=σ2/τ2\lambda = \sigma^2/\tau^2λ=σ2/τ2, this chooses the ridge penalty too — with no cross-validation and no held-out data.

6.7 Doing the optimization

Training is now an optimization problem, and Lecture 6 supplies the tools.

Optimize the logarithms. All hyperparameters must be positive. Optimize (log⁡σf2,log⁡ℓ,log⁡σ2)(\log\sigma_f^2,\log\ell,\log\sigma^2)(logσf2​,logℓ,logσ2) instead: the problem becomes unconstrained and better conditioned.

Use L-BFGS with the exact gradient. With α=Cθ−1y\alpha = C_\theta^{-1}yα=Cθ−1​y,

∂log⁡p(y∣θ)∂θj=12tr⁡ ⁣((αα⊤−Cθ−1) ∂Cθ∂θj).\frac{\partial\log p(y\mid\theta)}{\partial\theta_j} = \frac12\operatorname{tr}\!\Big(\big(\alpha\alpha^\top-C_\theta^{-1}\big)\,\frac{\partial C_\theta}{\partial\theta_j}\Big).∂θj​∂logp(y∣θ)​=21​tr((αα⊤−Cθ−1​)∂θj​∂Cθ​​).

Only the derivative of the kernel is needed. Check it against finite differences before trusting it.

Restart from several initializations. The marginal likelihood can have more than one local maximum. A common pair: a short length scale with small noise, where the function wiggles through every point; and a long length scale with large noise, where a smooth trend is seen through heavy scatter. Compare the marginal likelihood at each, and look at both fits.

Two cautions. This is still maximum likelihood, so with many hyperparameters it can overfit. And it only compares the kernels you offered it; it cannot tell you they are all wrong. It does not replace a held-out test set.

7. Step 3 — Inference: predictions at test points

7.1 The predictive distribution

We want the distribution of f⋆=f(x⋆)f^\star = f(x^\star)f⋆=f(x⋆) given the data. Under the model, the training targets and the test value are jointly Gaussian. Their covariances follow from the kernel, plus noise on the training targets only:

(yf⋆)∼N(0, (K+σ2Ik⋆k⋆⊤k⋆⋆)).\begin{pmatrix}y\\ f^\star\end{pmatrix}\sim\mathcal{N}\left(0,\ \begin{pmatrix}K+\sigma^2I & k^\star\\ k^{\star\top} & k^{\star\star}\end{pmatrix}\right).(yf⋆​)∼N(0, (K+σ2Ik⋆⊤​k⋆k⋆⋆​)).

Apply the Gaussian conditioning formula from Lecture 2 — for zero-mean (z1,z2)(z_1,z_2)(z1​,z2​),  z1∣z2∼N(Σ12Σ22−1z2, Σ11−Σ12Σ22−1Σ21)\ z_1\mid z_2\sim\mathcal{N}\big(\Sigma_{12}\Sigma_{22}^{-1}z_2,\ \Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}\big) z1​∣z2​∼N(Σ12​Σ22−1​z2​, Σ11​−Σ12​Σ22−1​Σ21​) — with z1=f⋆z_1 = f^\starz1​=f⋆ and z2=yz_2 = yz2​=y:

For a new noisy observation, add the noise back:  y⋆∣D∼N(μ⋆, v⋆+σ2)\ y^\star\mid\mathcal{D}\sim\mathcal{N}(\mu^\star,\ v^\star+\sigma^2) y⋆∣D∼N(μ⋆, v⋆+σ2).

That is all of GP prediction. No weights, no optimization, no step size — just conditioning a Gaussian.

7.2 The predictive mean

Using α=(K+σ2I)−1y\alpha = (K+\sigma^2I)^{-1}yα=(K+σ2I)−1y from training,

μ⋆=∑n=1Nαn k(xn,x⋆).\mu^\star = \sum_{n=1}^N\alpha_n\,k(x_n,x^\star).μ⋆=n=1∑N​αn​k(xn​,x⋆).

The prediction is a weighted sum of kernel bumps, one centered at each training input, with weights α\alphaα fixed during training. The model started with infinitely many features (§4.3), but its predictions live in an NNN-dimensional space set by the data. Models like this, whose effective size grows with the amount of data, are called nonparametric.

With the linear kernel, μ⋆\mu^\starμ⋆ equals Lecture 7's posterior mean mN⊤ϕ⋆m_N^\top\phi^\starmN⊤​ϕ⋆, which equals the ridge estimate of Lecture 5. The same prediction has now appeared three times.

7.3 The predictive variance

v⋆=k⋆⋆⏟prior variance−k⋆⊤(K+σ2I)−1k⋆⏟uncertainty removed by the data.v^\star = \underbrace{k^{\star\star}}_{\text{prior variance}}-\underbrace{k^{\star\top}\big(K+\sigma^2I\big)^{-1}k^\star}_{\text{uncertainty removed by the data}} .v⋆=prior variancek⋆⋆​​−uncertainty removed by the datak⋆⊤(K+σ2I)−1k⋆​​.

The variance is the prior variance, minus what the data has explained. Three consequences.

It returns to the prior far from the data. For a stationary kernel, k(xn,x⋆)→0k(x_n,x^\star)\to0k(xn​,x⋆)→0 as x⋆x^\starx⋆ moves away from every training input. So k⋆→0k^\star\to0k⋆→0, and

μ⋆→0,v⋆→k⋆⋆=σf2.\mu^\star\to0, \qquad v^\star\to k^{\star\star} = \sigma_f^2 .μ⋆→0,v⋆→k⋆⋆=σf2​.

Compare §2 carefully. The mean still returns to zero, the prior mean — that is fine. What changed is the variance: the model now reports the full prior uncertainty σf2\sigma_f^2σf2​ instead of claiming certainty. It says I don't know. The failure is repaired, and it was repaired by the prior.

It does not depend on yyy. Only the input locations appear in v⋆v^\starv⋆. You can compute where the model will be uncertain before taking any measurements. The next topic, Bayesian optimization, is built on exactly this.

The two kinds of uncertainty. For a new observation,

Var⁡[y⋆∣D]=σ2⏟aleatoric+v⋆⏟epistemic.\operatorname{Var}[y^\star\mid\mathcal{D}] = \underbrace{\sigma^2}_{\text{aleatoric}}+\underbrace{v^\star}_{\text{epistemic}} .Var[y⋆∣D]=aleatoricσ2​​+epistemicv⋆​​.

The aleatoric part is constant and irreducible. The epistemic part is small near data, larger between and beyond it, and approaches σf2\sigma_f^2σf2​ far away. With plentiful data, v⋆→0v^\star\to0v⋆→0 and only σ2\sigma^2σ2 remains: you can learn the function exactly and still not predict the next measurement exactly.

7.5 Show functions, not just bands

A plot of μ⋆±2v⋆\mu^\star\pm2\sqrt{v^\star}μ⋆±2v⋆​ shows the uncertainty at each input separately and hides how values at different inputs move together. Set this beside Lecture 7. The model changed from a prior on weights to a prior on functions. Where this goes. Bayesian optimization chooses where to evaluate an expensive function by balancing a high predicted value μ⋆\mu^\starμ⋆ against high uncertainty v⋆v^\starv⋆. Experimental design and active learning choose measurements to reduce v⋆v^\starv⋆ where it matters. All of them are built on the two formulas of §7.

Quiz-eligible facts

  1. Every method in the course has three steps: model, training, inference. MLE/MAP train by optimizing a single w^\hat ww^ and infer by plugging it in; Bayesian methods train by computing a posterior and infer by averaging over it.
  2. With a localized basis, Bayesian linear regression's predictive mean and epistemic variance go to zero far from the basis centers: confidently wrong.
  3. A prior w∼N(0,τ2I)w\sim\mathcal{N}(0,\tau^2I)w∼N(0,τ2I) induces a Gaussian prior on function values with Cov⁡[f(x),f(x′)]=τ2ϕ(x)⊤ϕ(x′)\operatorname{Cov}[f(x),f(x')] = \tau^2\phi(x)^\top\phi(x')Cov[f(x),f(x′)]=τ2ϕ(x)⊤ϕ(x′); the prior variance at xxx is τ2∥ϕ(x)∥2\tau^2\|\phi(x)\|^2τ2∥ϕ(x)∥2.
  4. Conditioning never increases variance. The posterior cannot be uncertain where the prior was certain, so the failure above is a failure of the prior.
  5. A kernel gives the prior covariance between function values. It is valid when every Gram matrix it produces is positive semi-definite; sums and products of valid kernels are valid.
