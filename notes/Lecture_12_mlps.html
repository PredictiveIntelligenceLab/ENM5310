What this lecture adds. Every model in this course so far has had the form "a linear function of features we chose." Bayesian linear regression chose ϕ\phiϕ explicitly; a GP chose it implicitly through the kernel. This lecture asks what happens when the features themselves become parameters, learned by the same maximum likelihood you already know. The answer is the multilayer perceptron. We will see where the idea came from, what it looks like geometrically, what can be proved about its expressive power, and — just as important — what cannot. Lecture 13 then deals with the practical consequence: these models are much harder to train, and most of modern deep learning practice is about making training work.

0. Where we are (4 min)

Look back at the models of Lectures 4–11 and they share a single template:

p(y∣x,w)=(likelihood)(y ∣ w⊤ϕ(x)),ϕ chosen by you. p(y\mid x,w) = \text{(likelihood)}\big(y \,\big|\, w^\top\phi(x)\big), \qquad \phi \text{ chosen by you.} p(y∣x,w)=(likelihood)(y∣∣​w⊤ϕ(x)),ϕ chosen by you.

Linear regression used ϕ(x)=x\phi(x)=xϕ(x)=x; Coding Assignment 1 used raw pixels, which is the same thing; Lecture 7 used polynomial or RBF features; Lectures 8–11 used a kernel, which Lecture 7 showed is k(x,x′)=τ2ϕ(x)⊤ϕ(x′)k(x,x')=\tau^2\phi(x)^\top\phi(x')k(x,x′)=τ2ϕ(x)⊤ϕ(x′) for some feature map, possibly infinite-dimensional. Because the unknowns www enter linearly, everything was tractable: closed-form or convex training, Gaussian posteriors, calibrated predictive variances.

The modeling skill in all of these was choosing ϕ\phiϕ — or, equivalently, choosing the kernel and its length scales. Today we stop choosing.

1. Why learn features? (8 min)

Fixed features fail in three distinct ways, and it is worth keeping them apart because they have different remedies.

Dimension. A basis built by tensor products — mmm functions per coordinate — has mdm^dmd elements. This is the same count that killed quadrature grids in Lecture 1. For d=2d=2d=2 it is harmless; for a 28×2828\times2828×28 image, d=784d=784d=784, and no tensor-product basis can even be written down. Kernels avoid the explicit count but not the underlying problem: a stationary kernel's notion of "nearby" is Euclidean distance in Rd\mathbb{R}^dRd, and in high dimensions almost every pair of points is far apart.

Geometry. Even when the dimension is manageable, Euclidean distance in the raw input space may be the wrong notion of similarity. Shift a handwritten digit two pixels to the right and its pixel vector moves far from the original — often farther than a different digit drawn in the same place. A squared-exponential kernel on pixels therefore believes that a shifted "3" is a different object. Logistic regression on pixels, as in Coding Assignment 1, has an even more restrictive geometry: its decision boundary is a single hyperplane in pixel space. Whatever you did in that assignment to push accuracy up, you did by changing ϕ\phiϕ.

Cost. GP training costs O(N3)O(N^3)O(N3) and each prediction costs O(N)O(N)O(N). With N=6×104N = 6\times10^4N=6×104 images, a single Cholesky factorization is of order 101410^{14}1014 floating-point operations, and modern datasets are larger by factors of 10310^3103 or more.

The proposal. Make the features learnable:

f(x;θ)=w⊤ϕ(x;ϑ)+b,θ=(w,b,ϑ), f(x;\theta) = w^\top\phi(x;\vartheta) + b, \qquad \theta = (w,b,\vartheta), f(x;θ)=w⊤ϕ(x;ϑ)+b,θ=(w,b,ϑ),

and fit everything, readout and features together, by maximum likelihood. If ϕ\phiϕ is built from cheap, differentiable, composable pieces, training can use SGD (Lecture 6), whose cost per epoch is linear in NNN and which runs on hardware built for matrix multiplication.

The bill. Be clear about what this gives up. The unknowns no longer enter linearly, so the loss is nonconvex and there is no closed form. There is no conjugate posterior, so the default output is a point estimate with no epistemic uncertainty. And the model has many more design choices — architecture, initialization, optimizer, schedule — each of which can silently break training. Lecture 13 is about paying this bill.

This trade is the one Sutton's Bitter Lesson (Week 0) argues has always won in the long run: general methods that scale with data and compute eventually beat methods that encode what we know. The scientific counterpoint (Welling, also Week 0) is that knowledge still matters — and over the coming weeks you will see it return, not as hand-chosen features, but as architectural structure: convolutions encode translation symmetry, operators encode resolution independence, attention encodes permutation structure.

2. A short history: three waves (12 min)

The ideas behind deep learning are old. What has changed, repeatedly, is whether they could be made to work. The standard periodization (Goodfellow et al., 2016, §1.2) has three waves.

Wave Years Core idea What made it possible Why it stalled
Cybernetics 1940s–1960s Neurons as threshold units; learning as weight adjustment Simple learning rules for single linear units A single linear unit cannot represent XOR; no way to train multiple layers
Connectionism 1980s–mid 1990s Networks of many simple units; distributed representations Backpropagation Deep networks would not train; small datasets; convex kernel methods matched or beat them
Deep learning 2006–present Many layers, trained end to end Large labeled datasets, GPUs, and a set of training techniques (ongoing)

First wave: cybernetics. McCulloch and Pitts (1943) modeled a neuron as a threshold on a weighted sum of binary inputs and showed networks of them could compute logical functions — but the weights were set by hand. Rosenblatt's perceptron (1958) added learning: update the weights whenever an example is misclassified. If the data are linearly separable, the rule provably converges in finitely many steps. At about the same time Widrow and Hoff's ADALINE (1960) trained a linear unit with the "least mean squares" rule, which is exactly SGD on squared error for linear regression — the algorithm of Lecture 6, sixty-five years earlier. Minsky and Papert's Perceptrons (1969) then made precise what a single layer cannot do: XOR is not linearly separable, so no single-layer perceptron computes it. Multilayer networks could, but nobody knew how to train their hidden weights. Funding and interest collapsed.

Second wave: connectionism. The missing algorithm was reverse-mode differentiation — computing the gradient of a scalar loss with respect to every weight in one backward sweep. It was described by Linnainmaa (1970) as a general automatic differentiation method and proposed for networks by Werbos (1974), but became widely known through Rumelhart, Hinton and Williams (1986), who showed that hidden units trained by backpropagation learn useful internal representations. A burst of results followed: LeCun and colleagues (1989) trained convolutional networks to read handwritten zip codes, later deployed to read bank checks; Cybenko (1989) and Hornik, Stinchcombe and White (1989) proved that one-hidden-layer networks are universal approximators (§5); Hochreiter and Schmidhuber (1997) introduced the LSTM.

Then the wave broke, for two reasons. The first was technical: Hochreiter (1991) and Bengio, Simard and Frasconi (1994) showed that gradients propagated through many layers tend to shrink or grow exponentially, so deep networks trained badly or not at all. The second was competitive: support vector machines and kernel methods (Cortes and Vapnik, 1995) and graphical models offered convex training, clean theory, and equal or better accuracy on the datasets of the day, which had thousands of examples, not millions. For roughly a decade, "neural networks" was not a phrase that helped a paper get accepted.

Third wave: deep learning. Hinton, Osindero and Teh (2006) showed that deep networks could be trained if each layer was first pretrained without labels, one at a time. That result revived interest, but its lasting contribution was to provoke the question: why does plain backpropagation from a random initialization fail? Glorot and Bengio (2010) — the paper at the center of Lecture 13 — traced much of the failure to how signals are scaled at initialization. Within a few years, layerwise pretraining was unnecessary: good initialization, non-saturating activations (ReLU), more data and faster hardware were enough.

The turning point was ImageNet. Deng et al. (2009) assembled a labeled image dataset two to three orders of magnitude larger than its predecessors, and the annual ILSVRC competition used 1.2 million training images in 1000 classes. In 2012, Krizhevsky, Sutskever and Hinton's AlexNet — a 60-million-parameter convolutional network with ReLUs and dropout, trained for about a week on two consumer GPUs — reached 15.3% top-5 test error against 26.2% for the next-best entry. Within three years the field had converged on deep networks for vision, speech and translation, and a stream of training techniques followed: Adam (2014), batch normalization and residual networks (2015), which allowed over a hundred layers.

Since 2017. The transformer (Vaswani et al., 2017) replaced recurrence with attention and turned out to scale: Kaplan et al. (2020) found that test loss falls as a smooth power law in model size, data and compute over many orders of magnitude. Some describe what followed — large pretrained "foundation" models, generative models of images and text, and now of molecules, materials and weather — as a fourth wave. In science, AlphaFold 2 (2020–21) predicted protein structures at near-experimental accuracy, and learned weather models such as GraphCast (2023) and Aurora (2025) now match or beat operational numerical forecasts on many metrics at a tiny fraction of the cost. The 2024 Nobel Prizes in Physics (Hopfield, Hinton) and Chemistry (Baker; Hassabis and Jumper) recognized both the foundations and the scientific payoff.

Three lessons to carry forward.

  1. The ideas are old; what changed was data, compute, and training technique. Multilayer networks trained by gradient descent are a 1986 idea. The 2012 network differed from a 1989 one mainly in scale and in a handful of training choices — ReLU, careful initialization, dropout, GPUs. Those choices are Lecture 13.
  2. Each winter followed a real technical obstacle, not just hype. The first was representational (linear separability). The second was optimization (vanishing gradients) compounded by small data.
  3. Expressiveness was never the bottleneck. Universal approximation was proved in 1989. The field still stalled for twenty years. Whether a network can represent a function and whether gradient descent will find it from finite data are different questions — which is exactly how §5 is organized.

3. The MLP in three steps (16 min)

3.1 The architecture

A multilayer perceptron (MLP), or fully connected feedforward network, alternates affine maps with elementwise nonlinearities:

h(0)=x,z(ℓ)=W(ℓ)h(ℓ−1)+b(ℓ),h(ℓ)=σ(z(ℓ)),ℓ=1,…,L−1, h^{(0)} = x,\qquad z^{(\ell)} = W^{(\ell)}h^{(\ell-1)} + b^{(\ell)},\qquad h^{(\ell)} = \sigma\big(z^{(\ell)}\big),\quad \ell=1,\dots,L-1, h(0)=x,z(ℓ)=W(ℓ)h(ℓ−1)+b(ℓ),h(ℓ)=σ(z(ℓ)),ℓ=1,…,L−1,
f(x;θ)=z(L)=W(L)h(L−1)+b(L). f(x;\theta) = z^{(L)} = W^{(L)}h^{(L-1)} + b^{(L)}. f(x;θ)=z(L)=W(L)h(L−1)+b(L).

The last layer has no activation; it produces the quantity that the likelihood needs (§3.2). Layers 1,…,L−11,\dots,L-11,…,L−1 are hidden layers. The parameter count is

∣θ∣=∑ℓ=1LHℓ (Hℓ−1+1). |\theta| = \sum_{\ell=1}^{L} H_\ell\,(H_{\ell-1}+1). ∣θ∣=ℓ=1∑L​Hℓ​(Hℓ−1​+1).

Why the nonlinearity is essential. Without σ\sigmaσ, the network is W(L)⋯W(1)x+constW^{(L)}\cdots W^{(1)}x + \text{const}W(L)⋯W(1)x+const, a single affine map. Depth adds nothing to what a linear network can represent; only the nonlinearity lets composition create new functions.

Read the network as a feature map plus a readout. Write ϕ(x;ϑ)=h(L−1)(x)\phi(x;\vartheta) = h^{(L-1)}(x)ϕ(x;ϑ)=h(L−1)(x). Then f(x;θ)=W(L)ϕ(x;ϑ)+b(L)f(x;\theta) = W^{(L)}\phi(x;\vartheta)+b^{(L)}f(x;θ)=W(L)ϕ(x;ϑ)+b(L) is exactly the linear predictor of Lectures 4–7, applied to features computed by the first L−1L-1L−1 layers. Everything you know about the last layer still holds; what is new is that ϕ\phiϕ is trained.

Two things differ from logistic regression.

The gradient is no longer something you derive by hand per model. It is computed by backpropagation, a systematic application of the chain rule that costs about as much as one extra forward pass. Lecture 13 §1 derives it for the MLP.

The objective is nonconvex. Logistic regression's loss was convex (Lecture 5), so any stationary point was the global minimum. An MLP's is not, and the reason is a symmetry you can see without computing anything.

Why the MLP loss is nonconvex.

  1. Let θ⋆\theta^\starθ⋆ minimize the training loss L\mathcal{L}L. Pick a hidden layer ℓ\ellℓ and a permutation π\piπ of its HℓH_\ellHℓ​ units. Permute the rows of W(ℓ)W^{(\ell)}W(ℓ) and entries of b(ℓ)b^{(\ell)}b(ℓ) by π\piπ, and the columns of W(ℓ+1)W^{(\ell+1)}W(ℓ+1) by the same π\piπ. Call the result πθ⋆\pi\theta^\starπθ⋆.
  2. The network computes the same function: unit jjj now sits in position π(j)\pi(j)π(j), but it still receives the same inputs and its output is still multiplied by the same outgoing weights. So L(πθ⋆)=L(θ⋆)\mathcal{L}(\pi\theta^\star)=\mathcal{L}(\theta^\star)L(πθ⋆)=L(θ⋆); every πθ⋆\pi\theta^\starπθ⋆ is a minimizer, and there are Hℓ!H_\ell!Hℓ​! of them.
  3. If L\mathcal{L}L were convex, its set of minimizers would be convex, so the average θˉ=1Hℓ!∑ππθ⋆\bar\theta = \frac{1}{H_\ell!}\sum_\pi \pi\theta^\starθˉ=Hℓ​!1​∑π​πθ⋆ would also be a minimizer.
  4. In θˉ\bar\thetaθˉ, every row of W(ℓ)W^{(\ell)}W(ℓ) equals the average row, and every column of W(ℓ+1)W^{(\ell+1)}W(ℓ+1) equals the average column. All HℓH_\ellHℓ​ units compute the same function: layer ℓ\ellℓ has effectively width one.
  5. A width-one layer generally fits worse than a width-HℓH_\ellHℓ​ one, contradicting step 3. Hence L\mathcal{L}L is not convex.

The same argument applies with sign flips of tanh units and positive rescalings of ReLU units. The landscape is full of equivalent minima related by symmetry. That by itself is harmless — any of them will do — but it means we have lost every guarantee convexity gave us, and we will need empirical judgment where we used to have theorems.

3.4 Step 3 — Inference

Prediction at a new input x∗x^\astx∗ is a single forward pass: y^=f(x∗;θ^)\hat y = f(x^\ast;\hat\theta)y^​=f(x∗;θ^), or softmax⁡(f(x∗;θ^))\operatorname{softmax}(f(x^\ast;\hat\theta))softmax(f(x∗;θ^)) for classification. Its cost depends on the network size, not on NNN — compare O(N)O(N)O(N) per GP prediction after an O(N3)O(N^3)O(N3) factorization.

What you get is a point estimate. The predictive distribution p(y∣x∗,θ^)p(y\mid x^\ast,\hat\theta)p(y∣x∗,θ^) contains the aleatoric noise model and nothing else; in the language of Lecture 7, the epistemic term is missing entirely. Far from the training data, a GP reverts to its prior and says so; a ReLU network extrapolates linearly, with whatever confidence its logits happen to imply. We return to this later in the course (ensembles, Bayesian neural networks). For now, remember that a well-trained MLP knows nothing about what it does not know.

4. Geometry: a network warps space (18 min)

The fastest route to intuition is to watch what a network does to its input space, layer by layer. Two resources make this concrete: Olah's 2014 post, which these notes follow, and the TensorFlow Playground (playground.tensorflow.org), where you can train small networks on 2D datasets and watch the hidden representations live.

4.1 Anatomy of one layer

A layer applies x↦σ(Wx+b)x\mapsto\sigma(Wx+b)x↦σ(Wx+b). Split it into its parts.

The affine map. By the SVD (Lecture 4), W=UΣV⊤W = U\Sigma V^\topW=UΣV⊤. Applying WWW means: rotate (or reflect) by V⊤V^\topV⊤; stretch each axis by a singular value, and — if Hℓ≠Hℓ−1H_\ell \ne H_{\ell-1}Hℓ​=Hℓ−1​ — either embed into a higher-dimensional space or discard directions; rotate again by UUU. Then bbb translates. Affine maps keep straight lines straight and parallel lines parallel.

The nonlinearity. σ\sigmaσ acts on each coordinate separately, so it bends the coordinate axes' directions differently from everything else.

  • tanh squashes: it is nearly linear near the origin and compresses everything far away into the cube (−1,1)Hℓ(-1,1)^{H_\ell}(−1,1)Hℓ​. It is a continuous bijection with a continuous inverse, so it bends space without tearing or gluing it.
  • ReLU folds and clips: it leaves the positive orthant untouched and projects every point with a negative coordinate onto the face where that coordinate is zero. It is not injective — distinct inputs can map to the same output — so information is discarded.

How nonlinear the layer is depends on the scale of Wx+bWx+bWx+b. If pre-activations stay within ∣z∣≲0.5|z|\lesssim 0.5∣z∣≲0.5, tanh is nearly the identity and the layer is nearly affine. If they are large, every unit saturates at ±1\pm1±1 and the layer maps most of space to the corners of a cube. The interesting regime is in between, and keeping the network there is the subject of initialization (Lecture 13 §3).

4.2 What a classifier does

For binary classification the last layer computes sigm⁡(w⊤h(L−1)(x)+b)\operatorname{sigm}\big(w^\top h^{(L-1)}(x)+b\big)sigm(w⊤h(L−1)(x)+b). The decision boundary is {x:w⊤h(L−1)(x)+b=0}\{x : w^\top h^{(L-1)}(x) + b = 0\}{x:w⊤h(L−1)(x)+b=0}: a hyperplane in the last hidden space, which pulled back through the earlier layers becomes a curved surface in input space.

This gives a clean way to say what the hidden layers are for: they deform the input space until the classes are linearly separable, so that the logistic regression on top can finish the job. In Coding Assignment 1 you were the deformation, choosing ϕ\phiϕ. Here gradient descent chooses it.

4.3 What a narrow network cannot do

Take a 2D dataset: class A is the disk ∥x∥≤1\lVert x\rVert\le1∥x∥≤1; class B is the annulus 2.5≤∥x∥≤3.52.5\le\lVert x\rVert\le3.52.5≤∥x∥≤3.5 surrounding it. Try to classify it with a tanh network whose hidden layers all have width 2.

  1. If W∈R2×2W\in\mathbb{R}^{2\times2}W∈R2×2 is invertible, x↦Wx+bx\mapsto Wx+bx↦Wx+b is a homeomorphism of the plane (continuous, bijective, continuous inverse). Elementwise tanh is a homeomorphism from R2\mathbb{R}^2R2 onto the open square (−1,1)2(-1,1)^2(−1,1)2. So each layer is a homeomorphism onto its image, and so is any composition of them.
  2. Homeomorphisms preserve the property "A is enclosed by B": the image of the disk still lies in a hole of the image of the annulus. Any path from a point of the disk's image to the outside of the image must cross the annulus's image.
  3. The final layer separates the classes with a line. Pick a point ppp in the disk's image and follow the ray from ppp pointing away from the line. It stays on ppp's side of the line, and it must cross the annulus's image on its way out. So some annulus point lies on the disk's side. No line separates them.
  4. If some WWW is singular, that layer collapses the plane onto a line, and every later layer sees only a single linear projection a⊤xa^\top xa⊤x. Along the line a⊤x=a⊤0a^\top x = a^\top 0a⊤x=a⊤0 through the disk's center, disk and annulus points share the same projection and therefore receive the same output. That does not help either.

So no width-2 tanh network can reach 100% training accuracy on this dataset, no matter how deep or how long it is trained. What you see in practice is a network that stretches a thin sliver of the annulus across the disk and misclassifies it.

Add a third dimension and the problem disappears. With three hidden units the network can lift the plane into R3\mathbb{R}^3R3 — think of pushing the disk down and the annulus up — where a plane separates them. The lesson: width is room to untangle. Topology constrains what a network of a given width can do, regardless of training. (Code Checkpoint B constructs such a separator by hand with three ReLUs.)

4.4 ReLU networks: linear regions and folding

A ReLU network computes a continuous piecewise linear function. Each first-layer unit max⁡(0,wj⊤x+bj)\max(0,w_j^\top x+b_j)max(0,wj⊤​x+bj​) switches on or off across the hyperplane wj⊤x+bj=0w_j^\top x + b_j = 0wj⊤​x+bj​=0, and the network is linear on every cell of the resulting arrangement.

For a single hidden layer of HHH units in Rd\mathbb{R}^dRd, the number of linear regions is at most ∑i=0d(Hi)\sum_{i=0}^{d}\binom{H}{i}∑i=0d​(iH​), the number of cells in an arrangement of HHH hyperplanes: polynomial in HHH, and in 1D just H+1H+1H+1.

Depth changes this count exponentially, because a later layer acts on the already folded space. The cleanest example is the tent map on [0,1][0,1][0,1]:

t(x)=2ReLU⁡(x)−4ReLU⁡(x−12)={2x,0≤x≤122−2x,12<x≤1 t(x) = 2\operatorname{ReLU}(x) - 4\operatorname{ReLU}(x-\tfrac12) = \begin{cases}2x, & 0\le x\le\tfrac12\\ 2-2x, & \tfrac12<x\le1\end{cases} t(x)=2ReLU(x)−4ReLU(x−21​)={2x,2−2x,​0≤x≤21​21​<x≤1​

It folds [0,1][0,1][0,1] in half and stretches it back onto [0,1][0,1][0,1]. Composing it kkk times, t(k)=t∘⋯∘tt^{(k)} = t\circ\cdots\circ tt(k)=t∘⋯∘t, folds the interval kkk times and produces a sawtooth with 2k−12^{k-1}2k−1 teeth and 2k2^k2k linear pieces, using a network with kkk hidden layers of 2 units. A one-hidden-layer network has at most H+1H+1H+1 pieces in 1D, so it needs at least 2k−12^k-12k−1 units to represent the same function. Telgarsky (2016) turned this into a theorem: there are functions computed by deep, narrow ReLU networks that shallow networks cannot even approximate without exponentially many units.

Geometrically: a shallow network cuts space with hyperplanes; a deep network folds space and cuts the folded result, so every later cut is replicated across every fold. Montúfar et al. (2014) show that the maximal number of linear regions grows exponentially with depth for fixed width.

Two cautions. The maximum is not the typical: randomly initialized and trained networks usually have far fewer regions than the bound. And "more regions" is not the same as "better" — it is a statement about what depth makes possible, which is the subject of the next section.

5.4 Rates, dimension, and why learned features win

The first row — how many units — is where the real argument for learned features lives.

Fixed features suffer the curse of dimensionality. The construction of §5.1 extends to ddd dimensions on a grid of spacing hhh, which needs on the order of h−dh^{-d}h−d units (plus a little extra depth to build ddd-dimensional hats). The error is still O(h2)O(h^2)O(h2), so with HHH units

Be honest about the fine print. The dimension has not vanished; it has moved into the constant CfC_fCf​ and into the choice of function class. The theorem says that if the function you care about is "simple" in Barron's sense, a network can exploit that without being told what the simplicity is.

Depth helps for compositional functions. One hidden layer is universal, so depth is never needed for possibility. It is needed for efficiency when the target is built by composition — and the sawtooth of §4.4 is the proof that the gap can be exponential. Many functions in science and engineering have this structure: a quantity computed from a quantity computed from local interactions. Poggio et al. Summary of §5. Shallow networks are universal; so are polynomials. The reason to use networks is that, for structured targets, they need far fewer parameters than any fixed basis, and depth multiplies that advantage for compositional structure. None of this says that training will find those parameters.

7. Summary and bridge (3 min)

An MLP is logistic or linear regression on top of a learned feature map built from alternating affine maps and elementwise nonlinearities. The likelihood and the loss are unchanged from Lectures 4–5; what changes is that the features are trained, which buys a much better rate of approximation for structured targets, at the price of a nonconvex objective and a point estimate with no epistemic uncertainty.

Geometrically, each layer rotates, stretches and shifts space, then squashes or folds it; the hidden layers exist to untangle the data until a hyperplane suffices. Width gives room to untangle; depth multiplies the number of folds.

Universal approximation says a large enough network can represent any continuous function. It does not say how large, whether the parameters can be estimated from finite data, or whether gradient descent will find them. The history of the field is the history of those last two questions — and Lecture 13 is about how practice answers them: how gradients are computed, how signals are kept at the right scale, how the optimizer is configured, and how overfitting is controlled.

  1. An MLP without nonlinearities is an affine map, regardless of depth.
  2. The last layer of an MLP classifier is logistic (or multinomial logistic) regression on the learned features h(L−1)h^{(L-1)}h(L−1); the loss is the negative log-likelihood of the chosen likelihood, unchanged from Lectures 4–5.

  5. Each layer is an affine map (rotate–stretch–rotate–shift, by the SVD) followed by an elementwise squash (tanh) or fold/clip (ReLU).
  6. Width-2 tanh networks cannot perfectly separate a disk from a surrounding annulus, because their layers are homeomorphisms or projections; a third dimension makes it possible.

Practice problems

P1. A colleague builds a 10-layer network with identity activations and claims it is "more expressive than linear regression because it is deep." Is it? Is its training loss convex in the weights?

Answer. No: W(10)⋯W(1)xW^{(10)}\cdots W^{(1)}xW(10)⋯W(1)x is a single linear map, so the function class is that of linear regression. But the loss is not convex in the individual matrices. The scalar case shows it: (w2w1−1)2(w_2w_1-1)^2(w2​w1​−1)2 has a saddle at w1=w2=0w_1=w_2=0w1​=w2​=0 and two separate curves of minima. Depth changes the landscape without changing the function class.

P2. How many hidden units does a one-hidden-layer ReLU network need to represent the piecewise linear interpolant of fff at 101 equally spaced nodes on [0,1][0,1][0,1]? If f∈C2f\in C^2f∈C2, by roughly what factor does the maximum error fall when you double the number of nodes? What happens to the required number of units in ddd dimensions at fixed accuracy?

Answer. 100 units (one per interval: s1s_1s1​ for the first, then one per slope change). Doubling the nodes halves hhh, so the error falls by about 4. On a ddd-dimensional grid the count scales as h−dh^{-d}h−d, so H∼ε−d/2H\sim\varepsilon^{-d/2}H∼ε−d/2.

P3. You train a tanh network with three hidden layers, each of width 2, on the disk-inside-annulus dataset. After a very long training run, training accuracy is stuck at 97%. Is the optimizer to blame? What single change would you make?

Answer. No. Every layer is a homeomorphism onto its image (or a projection if WWW is singular), so the disk's image stays enclosed by the annulus's image and no line in the last hidden space separates them; 100% is unreachable for any training procedure. Increase the hidden width to 3 or more.

P4. Is a one-hidden-layer network with activation σ(z)=z2\sigma(z) = z^2σ(z)=z2 a universal approximator?

Answer. No. Each (wj⊤x+bj)2(w_j^\top x+b_j)^2(wj⊤​x+bj​)2 is a quadratic polynomial, so any sum of them is a polynomial of degree at most 2, however many units are used. Universality requires a non-polynomial activation.
