The point of this lecture. Lecture 16 ended with a layer that lets every token read from every other, with weights computed from content, in parallel. It also ended with a problem: that layer treats its input as a set. Today we finish the job. Add position, run attention in several heads, and wrap it with the three tools from Lecture 13 — a per-token MLP, residual connections, and LayerNorm — and you have the transformer block. Stack blocks, choose a mask, and you get the three transformer families behind modern language, vision and scientific models. The architecture is less mysterious than its reputation: every piece is something you already know.

0. Where we are, and what is missing (5 min)

Self-attention (Lecture 16 §5) maps a sequence XXX to

Y=softmax⁡ ⁣((XWQ)(XWK)⊤dk)XWV. Y = \operatorname{softmax}\!\Big(\frac{(XW_Q)(XW_K)^\top}{\sqrt{d_k}}\Big)XW_V . Y=softmax(dk​​(XWQ​)(XWK​)⊤​)XWV​.

Each output row is a content-weighted average of all value rows. It is global and parallel. But a single attention layer, used alone, has four shortcomings, and each section below fixes one.

  1. It ignores order. It is permutation equivariant, so "dog bites man" and "man bites dog" are the same input. → §1, positional encodings.
  2. It computes one weighted average per token. A token often needs several different kinds of information at once. → §2, multiple heads.
  3. It only mixes. Every output is a convex combination of value vectors; nothing transforms each token nonlinearly. Stacks of attention-only layers lose expressive power with depth — their outputs collapse toward rank one (Dong et al., 2021). → §3, a per-token MLP.
  4. It is one layer. Deep stacks need the signal-scale and gradient-flow tools of Lecture 13. → §3, residual connections and LayerNorm.

1. Positional information (10 min)

1.1 Add position to content

Self-attention sees a set, so we make each token's position part of its content before the first layer:

X(0)=Xin+P,pi∈Rd encodes position i. X^{(0)} = X_{\text{in}} + P, \qquad p_i\in\mathbb{R}^d \text{ encodes position } i . X(0)=Xin​+P,pi​∈Rd encodes position i.

After this, permuting the tokens changes their representations, and the network can learn to use order. Adding (rather than concatenating) keeps the width at ddd. In high dimensions the content and position vectors are close to orthogonal, so the network can still read each of them separately.

1.2 Sinusoidal encodings

Vaswani et al. (2017) use, for r=0,…,d/2−1r = 0,\dots,d/2-1r=0,…,d/2−1,

pi,2r=sin⁡(i ωr),pi,2r+1=cos⁡(i ωr),ωr=10000−2r/d. p_{i,2r} = \sin(i\,\omega_r), \qquad p_{i,2r+1} = \cos(i\,\omega_r), \qquad \omega_r = 10000^{-2r/d}. pi,2r​=sin(iωr​),pi,2r+1​=cos(iωr​),ωr​=10000−2r/d.

Each pair of coordinates is a clock hand rotating at its own frequency as iii increases. The frequencies are geometrically spaced, from one radian per position down to about 10−410^{-4}10−4. Fast hands distinguish neighbors; slow hands distinguish positions far apart. Together they work like the digits of a number in base 10 — except that the digits are smooth.

Fix one frequency ω\omegaω and write pi=(sin⁡iω, cos⁡iω)p_i = (\sin i\omega,\ \cos i\omega)pi​=(siniω, cosiω).

  1. Shifting is a rotation. By the angle-addition formulas,
pi+Δ=(cos⁡Δωsin⁡Δω−sin⁡Δωcos⁡Δω)pi, p_{i+\Delta} = \begin{pmatrix}\cos\Delta\omega & \sin\Delta\omega\\ -\sin\Delta\omega & \cos\Delta\omega\end{pmatrix}p_i , pi+Δ​=(cosΔω−sinΔω​sinΔωcosΔω​)pi​,

a rotation that depends on the offset Δ\DeltaΔ but not on iii. A linear map can therefore express "the token Δ\DeltaΔ positions back" in the same way everywhere. 2. 1.4 Other choices

  • Learned embeddings: one trainable vector per position. Simple and common, but undefined beyond the longest training sequence.
  • Rotary embeddings (RoPE; Su et al., 2024**):** instead of adding pip_ipi​, rotate each query and key pair by angle iωri\omega_riωr​ before the dot product. Then (Riq)⊤(Rjk)=q⊤Rj−ik(R_iq)^\top(R_jk) = q^\top R_{j-i}k(Ri​q)⊤(Rj​k)=q⊤Rj−i​k, so attention scores depend on content and on the relative offset j−ij-ij−i only. Most current language models use RoPE.
  • Physical coordinates. For a token that is a grid point, a particle or a sensor, the natural "position" is its coordinate (x,y,z,t)(x,y,z,t)(x,y,z,t). Encoding it with sinusoids of several frequencies is exactly the Fourier-feature embedding that counters spectral bias in coordinate networks. This also lets the model take tokens at arbitrary, irregular locations.

Remember. Add a positional encoding to each token before the first layer. Sinusoidal encodings are multi-frequency clocks: a shift is a rotation, and pi⊤pjp_i^\top p_jpi⊤​pj​ depends only on i−ji-ji−j. For physical data, Fourier features of the coordinates play the same role.

2. Multi-head attention (10 min)

2.1 Several lookups in parallel

One attention layer gives each token a single weighted average. But in "the animal didn't cross the street because it was too tired," the token "it" needs to find its referent, and also its verb, and also its neighbors. A particle in a molecule feels short-range repulsion and long-range electrostatics. One softmax cannot put sharp weight on several unrelated places at once without blurring them together.

Multi-head attention runs hhh attentions in parallel, each with its own projections of reduced width dk=d/hd_k=d/hdk​=d/h, and mixes their concatenated outputs:

headr=Attention⁡(XWQ(r), XWK(r), XWV(r); M)∈Rn×dk,r=1,…,h, \text{head}_r = \operatorname{Attention}\big(XW_Q^{(r)},\,XW_K^{(r)},\,XW_V^{(r)};\,M\big)\in\mathbb{R}^{n\times d_k},\qquad r=1,\dots,h, headr​=Attention(XWQ(r)​,XWK(r)​,XWV(r)​;M)∈Rn×dk​,r=1,…,h,

3. The transformer block (20 min)

3.1 Communicate, then compute

A transformer block has two sublayers, each wrapped in a residual connection with LayerNorm. In the pre-LN form used by essentially all modern transformers:

Z=X+MHA⁡(LN⁡(X))tokens exchange informationX′=Z+FFN⁡(LN⁡(Z))each token is processed on its own \begin{aligned} Z &= X + \operatorname{MHA}\big(\operatorname{LN}(X)\big) &&\text{tokens exchange information}\\ X' &= Z + \operatorname{FFN}\big(\operatorname{LN}(Z)\big) &&\text{each token is processed on its own} \end{aligned} ZX′​=X+MHA(LN(X))=Z+FFN(LN(Z))​​tokens exchange informationeach token is processed on its own​

where the feed-forward network is a two-layer MLP (Lecture 12) applied to every row separately, with shared weights:

FFN⁡(z)=σ(zW1+b1)W2+b2,W1∈Rd×4d, W2∈R4d×d, σ=GELU. \operatorname{FFN}(z) = \sigma\big(zW_1+b_1\big)W_2+b_2,\qquad W_1\in\mathbb{R}^{d\times4d},\ W_2\in\mathbb{R}^{4d\times d},\ \sigma=\text{GELU}. FFN(z)=σ(zW1​+b1​)W2​+b2​,W1​∈Rd×4d, W2​∈R4d×d, σ=GELU.

A useful picture: the rows of XXX are people at a meeting. In the attention sublayer they talk — each one listens to everyone and takes notes, weighted by relevance. In the FFN sublayer each person goes off and thinks alone about what they heard. A transformer is LLL rounds of "talk, then think."

3.2 What each component is for

Component Role Without it
Multi-head attention Mixes information across tokens, with content-dependent weights Tokens never interact: the model is an MLP applied to each token separately
FFN Transforms each token nonlinearly; holds about two-thirds of the parameters Outputs are only weighted averages of values; deep attention-only stacks collapse in rank
Residual connections Each sublayer adds a correction to a running representation; the identity path carries gradients through depth (Lecture 13) Deep stacks become hard to train
LayerNorm Re-standardizes each token before each sublayer, so inputs to attention and FFN stay at unit scale (Lecture 13) Scales drift with depth; softmax and GELU saturate

The attention sublayer is the only place where tokens interact. The FFN is the only place with a nonlinearity applied to individual tokens. A CNN alternates the same two operations — a spatial convolution that mixes neighbors and a 1×11\times11×1 convolution plus ReLU that acts on each pixel (Lecture 14 §2.3) — except that attention mixes globally, with weights it computes on the fly.

3.3 The residual stream

Unroll the residual connections across all LLL blocks:

X(L)=X(0)+∑ℓ=1L(MHA⁡ℓ(⋯ )+FFN⁡ℓ(⋯ )). X^{(L)} = X^{(0)} + \sum_{\ell=1}^{L}\Big(\operatorname{MHA}_\ell(\cdots) + \operatorname{FFN}_\ell(\cdots)\Big). X(L)=X(0)+ℓ=1∑L​(MHAℓ​(⋯)+FFNℓ​(⋯)).

The final representation is the input embedding plus the sum of every sublayer's contribution. Each sublayer reads the current stream (through LayerNorm) and writes an update back into it. This residual stream view (Elhage et al., 2021) explains why transformers train stably at great depth: as in Lecture 13 §3, the backward pass always has a direct identity path from the loss to every layer.

3.4 Pre-LN versus post-LN

The original transformer placed LayerNorm after the residual addition: X′=LN⁡(X+Sublayer⁡(X))X' = \operatorname{LN}\big(X + \operatorname{Sublayer}(X)\big)X′=LN(X+Sublayer(X)) ("post-LN"). Then the identity path passes through a LayerNorm at every block, gradients near the output are large at initialization, and training is unstable without a careful learning-rate warmup (Xiong et al., 2020). Pre-LN keeps the identity path clean, trains more robustly, and adds one final LayerNorm after the last block. When you read the 2017 paper, keep this difference in mind.

4. Masks and the three families (12 min)

The block is the same everywhere. Transformers differ in who may attend to whom, set by the mask, and in whether there is a second sequence to read from.

4.1 Encoder-only: bidirectional

No mask (M=0M=0M=0): every token sees every other, before and after it. The output is a contextual representation of each token, informed by the whole sequence. Use it when the entire input is available and you want to label, classify or regress from it: sentiment, the properties of a molecule, the class of an image, a field reconstructed from a full set of measurements. BERT (Devlin et al., 2019) is trained by masking 15% of the input tokens and predicting them from both sides. The Vision Transformer (§5) is encoder-only.

4.2 Decoder-only: causal

The causal mask of Lecture 16 sets Mij=−∞M_{ij}=-\inftyMij​=−∞ for j>ij>ij>i: token iii sees only itself and its past.

M=(0−∞−∞−∞00−∞−∞000−∞0000)⟹α=(1000∗∗00∗∗∗0∗∗∗∗). The output at position ttt predicts token t+1t+1t+1. This is the autoregressive factorization of Lecture 15,

p(y1:n)=∏t=1np(yt∣y<t), p(y_{1:n}) = \prod_{t=1}^{n}p(y_t\mid y_{<t}), p(y1:n​)=t=1∏n​p(yt​∣y<t​),

with every conditional computed by the same network. GPT (Radford et al., 2018) and most current large language models are decoder-only.

Training is parallel. Feed the whole true sequence; the mask guarantees that position ttt's prediction uses only y≤ty_{\le t}y≤t​. One forward pass yields all nnn next-token predictions, and the loss is their summed cross-entropy. This is teacher forcing (Lecture 15 §6) for the entire sequence at once — what an RNN needed nnn sequential steps to do.

Generation is still sequential. At test time, sample yn+1y_{n+1}yn+1​, append it, and run again. Each new token needs one forward pass. Since the keys and values of earlier tokens never change, they are stored and reused (a "KV cache"), so each step processes only the newest token.

5. What goes in and what comes out: tokens and heads (8 min)

A transformer operates on a set of ddd-dimensional vectors. Anything you can turn into such a set, it can process.

5.1 Tokenization and embedding

  • Text. Split into subword units from a fixed vocabulary V\mathcal VV (tens of thousands of entries), and look up each token's row of a learned embedding matrix E∈R∣V∣×dE\in\mathbb{R}^{|\mathcal V|\times d}E∈R∣V∣×d.
  • Images: patches. The Vision Transformer (ViT; Dosovitskiy et al., 2021) cuts an image into 16×1616\times1616×16 patches, flattens each, and maps it to ddd dimensions with one linear layer — a convolution with kernel size and stride 16. A 224×224224\times224224×224 image becomes 14×14=19614\times14=19614×14=196 tokens.
  • Physical fields. The same patching applies to a simulation snapshot: a 256×256256\times256256×256 field in 16×1616\times1616×16 patches gives 256 tokens instead of 65,536. Irregular data — particles, mesh nodes, sensors — can be tokenized point by point, with Fourier features of the coordinates as positional encoding (§1.4).
  • Time series. Each time step, or each short window of steps, becomes a token.

5.2 Output heads and likelihoods

The final representations X(L)X^{(L)}X(L) are mapped to whatever the likelihood needs, exactly as in Lecture 12 §3.

Task Head on each relevant row Likelihood and loss
Next-token prediction Linear map to $ \mathcal V
Classification of a whole input Average the rows (or use a dedicated summary token), then a linear map Categorical; cross-entropy
Regression of a field or next state Linear map to the output dimension per token or per patch Gaussian; squared error

Averaging the rows is the global average pooling of Lecture 14 §3.4: it turns permutation-equivariant token features into a permutation-invariant prediction.

6. Training a transformer (8 min)

Nothing in Lecture 13 is replaced; some of it becomes essential.

  • Objective: maximum likelihood, as always. For a decoder-only language model, the average cross-entropy of next-token predictions; exp⁡(that average)\exp(\text{that average})exp(that average) is the perplexity.
  • Optimizer: AdamW (Lecture 13 §5). Large language models typically use β=(0.9, 0.95)\beta=(0.9,\,0.95)β=(0.9,0.95) and weight decay around 0.10.10.1, not applied to biases, LayerNorm gains or embeddings.
  • Schedule: linear warmup, then cosine decay. Warmup matters more here than for MLPs, especially with post-LN (§3.4).
  • Gradient clipping at a norm of about 1. Occasional loss spikes are common at scale.
  • Regularization: dropout on attention weights and sublayer outputs for small datasets; large models trained on huge datasets often use little or none.

Data hunger and inductive bias. A CNN is told by its architecture that images are translation equivariant and local. A transformer is told only that its input is a set, plus whatever the positional encodings convey. It must learn locality from data. This is why ViTs trained on ImageNet's 1.3 million images lag behind comparable CNNs unless trained with heavy augmentation, and overtake them when pretrained on hundreds of millions of images (Dosovitskiy et al., 2021). With little data, structure built into the architecture wins. With a lot, a flexible model wins.

Scaling. Transformer test loss falls smoothly, as a power law, as model size, data and compute grow together (Kaplan et al., 2020). For a fixed compute budget, the best results come from scaling parameters and training tokens in proportion, roughly 20 tokens per parameter (Hoffmann et al., 2022). This predictability, as much as raw accuracy, is why the field consolidated around this architecture.

7. The whole thing in pseudocode (8 min)

A complete decoder-only transformer forward pass, in NumPy-style Python. Parameters live in a dictionary-like object P; a batch dimension is omitted for clarity.

import numpy as np

def softmax(z):                                  # row-wise, numerically stable
    z = z - z.max(-1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(-1, keepdims=True)

def layer_norm(x, g, b, eps=1e-5):               # normalize each row (token)
    mu, var = x.mean(-1, keepdims=True), x.var(-1, keepdims=True)
    return g * (x - mu) / np.sqrt(var + eps) + b

def gelu(x):
    return 0.5 * x * (1 + np.tanh(0.79788456 * (x + 0.044715 * x**3)))

def positional_encoding(n, d):                   # sinusoidal, Section 1.2
    pos, r = np.arange(n)[:, None], np.arange(d // 2)[None, :]
    w = 10000.0 ** (-2 * r / d)
    pe = np.zeros((n, d))
    pe[:, 0::2], pe[:, 1::2] = np.sin(pos * w), np.cos(pos * w)
    return pe

def mha(x, p, h, mask):                          # x: (n, d) -> (n, d)
    n, d = x.shape; dk = d // h
    split = lambda t: t.reshape(n, h, dk).transpose(1, 0, 2)   # (h, n, dk)
    q, k, v = split(x @ p.Wq), split(x @ p.Wk), split(x @ p.Wv)
    s = q @ k.transpose(0, 2, 1) / np.sqrt(dk) + mask          # (h, n, n)
    y = softmax(s) @ v                                         # (h, n, dk)
    return y.transpose(1, 0, 2).reshape(n, d) @ p.Wo           # concat heads, mix

def ffn(x, p):                                   # per-token MLP, d -> 4d -> d
    return gelu(x @ p.W1 + p.b1) @ p.W2 + p.b2

def block(x, p, h, mask):                        # pre-LN block, Section 3.1
    x = x + mha(layer_norm(x, p.ln1_g, p.ln1_b), p, h, mask)  # communicate
    x = x + ffn(layer_norm(x, p.ln2_g, p.ln2_b), p)           # compute
    return x

def transformer_lm(tokens, P):                   # tokens: (n,) integer ids
    n = len(tokens)
    x = P.E[tokens] + positional_encoding(n, P.d)              # (n, d)
    mask = np.triu(np.full((n, n), -np.inf), k=1)              # causal, Section 4.2
    for p in P.blocks:                                         # L blocks
        x = block(x, p, P.h, mask)
    x = layer_norm(x, P.lnf_g, P.lnf_b)                        # final LN (pre-LN)
    return x @ P.Wu                                            # (n, |V|) logits

def loss(tokens, P):                             # next-token cross-entropy
    logits = transformer_lm(tokens, P)[:-1]                    # rows 0..n-2
    targets = tokens[1:]                                       # predict t+1
    logp = np.log(softmax(logits))                             # log-probabilities
    return -logp[np.arange(len(targets)), targets].mean()

Four things to notice:

  1. The whole architecture is about thirty lines. Most of the complexity in real code is batching, efficiency and distributed training, not the model.
  2. Heads are a reshape. One d×dd\times dd×d projection is split into hhh blocks of width d/hd/hd/h; no separate weights per head are needed.
  3. The mask is the only difference between an encoder and a decoder. Replace mask by zeros and transformer_lm becomes an encoder (with a different head and loss).
  4. The causal loss uses every position at once: one call computes n−1n-1n−1 predictions and their cross-entropies.

For an encoder–decoder, add a cross-attention sublayer to each decoder block, computing queries from the decoder stream and keys and values from the encoder output.

8. Transformers in science, and their limits (7 min)

8.1 Where they are used

  • Protein structure. AlphaFold 2 (Jumper et al., 2021) is built around attention over residues and pairs of residues.
  • Weather and climate. Transformer-based models such as Pangu-Weather (Bi et al., 2023) and the Aurora foundation model (Bodnar et al., 2025) tokenize the atmosphere into 3D patches and forecast at accuracy competitive with operational systems, at a small fraction of the computational cost.
  • Learned simulators and neural operators. Fields, meshes and point clouds are tokenized as in §5, and transformers map them to future states or to solutions of PDEs.

8.2 Attention as a learned integral operator

There is a deeper reason transformers suit physical fields. If the tokens are samples v(xj)v(x_j)v(xj​) of a function at points xjx_jxj​, one attention head computes

y(xi)=∑j=1nα(xi,xj) v(xj)  ≈  ∫κ(xi,x′) v(x′) dx′, y(x_i) = \sum_{j=1}^{n}\alpha(x_i,x_j)\,v(x_j) \;\approx\; \int\kappa(x_i,x')\,v(x')\,dx', y(xi​)=j=1∑n​α(xi​,xj​)v(xj​)≈∫κ(xi​,x′)v(x′)dx′,

a quadrature approximation of an integral operator with a learned, input-dependent kernel κ\kappaκ. The softmax normalization makes the weights behave like quadrature weights, so refining the grid adds terms to the sum without changing what it approximates. Linear operators of this form — Green's functions, convolutions, projections — are how PDE solutions are written. Attention layers can therefore be seen as discretizations of operators between function spaces (Kovachki et al., 2023), which is the starting point for neural operators later in the course.

8.3 Limits

  • Quadratic cost. O(n2)O(n^2)O(n2) in the number of tokens makes fine 3D fields expensive. Remedies include patching, local or windowed attention, and approximations that are linear in nnn.
  • Weak inductive bias. With little data, CNNs (with locality and translation equivariance built in) or GPs (with an explicit prior) are often better. Small scientific datasets are the norm, not the exception.
  • No physics by default. Conservation laws, symmetries beyond permutation, and boundary conditions are not built in; they must be added through the data, the loss, or the architecture.

8.4 The architectures side by side

9. Summary (2 min)

A transformer turns its input into tokens, adds positional information, and passes the sequence through LLL identical blocks. Each block lets tokens exchange information through multi-head self-attention, then processes each token through an MLP, with residual connections and LayerNorm around both. The mask decides who sees whom: none for encoders, causal for decoders, and an extra cross-attention sublayer for encoder–decoders. A causal decoder computes every conditional of the autoregressive factorization in one parallel pass, which is why it trains so much faster than an RNN. Every ingredient — the attention of Lecture 16, the MLP of Lecture 12, the residuals, LayerNorm and AdamW of Lecture 13, the patches and pooling of Lecture 14, the autoregressive likelihood of Lecture 15 — was already in hand; the transformer is a particular way of putting them together that happens to scale.

Quiz-eligible facts

  1. Self-attention alone is permutation equivariant; positional encodings pip_ipi​ added to the input give the model access to order.
  2. Sinusoidal encodings use frequencies ωr=10000−2r/d\omega_r = 10000^{-2r/d}ωr​=10000−2r/d; a shift by Δ\DeltaΔ is a rotation of each (sin⁡,cos⁡)(\sin,\cos)(sin,cos) pair, and pi⊤pjp_i^\top p_jpi⊤​pj​ depends only on i−ji-ji−j.
  3. Rotary embeddings rotate queries and keys so that scores depend on the relative offset j−ij-ij−i.
  4. Multi-head attention runs hhh heads of width d/hd/hd/h, concatenates them and applies WOW_OWO​; it has 4d24d^24d2 parameters regardless of hhh.
  5. Pre-LN block: Z=X+MHA⁡(LN⁡(X))Z = X+\operatorname{MHA}(\operatorname{LN}(X))Z=X+MHA(LN(X)), X′=Z+FFN⁡(LN⁡(Z))X' = Z+\operatorname{FFN}(\operatorname{LN}(Z))X′=Z+FFN(LN(Z)), with FFN⁡\operatorname{FFN}FFN a per-token MLP of hidden width 4d4d4d.
  6. Attention is the only sublayer in which tokens interact; the FFN acts on each token separately and holds about two-thirds of a block's parameters.
  7. A block has about 12d212d^212d2 parameters; its cost is O(nd2+n2d)O(nd^2+n^2d)O(nd2+n2d).
  8. Post-LN (the original placement) puts LayerNorm on the residual path and needs careful warmup; pre-LN keeps a clean identity path.
  9. Encoder-only: no mask (BERT, ViT). Decoder-only: causal mask (GPT). Encoder–decoder: causal decoder plus cross-attention with queries from the decoder and keys and values from the encoder.
  10. A causal decoder computes all nnn next-token predictions in one parallel pass during training; generation is sequential, one token per forward pass, with cached keys and values.
  11. ViT tokenizes an image into 16×1616\times1616×16 patches with a linear map; a 224×224224\times224224×224 image gives 196 tokens.
  12. Transformers have weak inductive bias: with limited data, CNNs or GPs often do better; with large data, transformers overtake them.
  13. On sampled functions, an attention head is a quadrature of an integral operator with a learned, input-dependent kernel.
