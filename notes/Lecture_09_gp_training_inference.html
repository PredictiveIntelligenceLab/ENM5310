1. Recap: the model, and the three steps

Every method in this course has three steps: model, training, inference. Lecture 8 completed the first.

Step 1 — Model.  f∼GP(0,kθ)\ f\sim\mathcal{GP}(0,k_\theta) f∼GP(0,kθ​), and  yn=f(xn)+ϵn\ y_n = f(x_n)+\epsilon_n yn​=f(xn​)+ϵn​ with ϵn∼N(0,σ2)\epsilon_n\sim\mathcal{N}(0,\sigma^2)ϵn​∼N(0,σ2).

There are no weights. The unknowns are the function fff and the hyperparameters θ=(σf2,ℓ,σ2)\theta = (\sigma_f^2,\ell,\sigma^2)θ=(σf2​,ℓ,σ2).

Three facts from Lecture 8 that the rest of this lecture uses. A Gaussian prior on weights is a Gaussian prior on function values, with covariance k(x,x′)=τ2ϕ(x)⊤ϕ(x′)k(x,x') = \tau^2\phi(x)^\top\phi(x')k(x,x′)=τ2ϕ(x)⊤ϕ(x′) — so the kernel is the prior. A kernel is valid when every Gram matrix it produces is positive semi-definite, and Mercer's theorem says every valid kernel is an inner product of features. And a stationary kernel, one depending only on x−x′x-x'x−x′, has constant prior variance k(x,x)=σf2k(x,x) = \sigma_f^2k(x,x)=σf2​, which is what prevents the confident-and-wrong extrapolation that sank the fixed RBF basis.

2. Step 2 — Training: the marginal likelihood

2.1 What is there to learn, and how?

Two kinds of unknown came out of Step 1, and they get different treatment.

  • The function fff. Infinitely many values, of which the data touches NNN. Following Lecture 7, we keep a full distribution over it and never commit to one function. That happens in Step 3.
  • The hyperparameters θ\thetaθ. Three numbers describing the kind of function — its amplitude, its smoothness, and how noisy the observations are. These are few, and the data typically pins them down, so we choose single best values in the spirit of Lecture 4.

So Step 2 reduces to: find good values of θ\thetaθ. The natural first attempt is the principle from Lecture 4 — maximize the likelihood.

2.2 Why not maximize the likelihood over everything?

Try maximizing jointly over the function and the noise:

p(y∣f,σ2)=∏n=1NN(yn ∣ f(xn), σ2).p(y\mid f,\sigma^2) = \prod_{n=1}^{N}\mathcal{N}\big(y_n\,\big|\,f(x_n),\,\sigma^2\big).p(y∣f,σ2)=n=1∏N​N(yn​∣∣​f(xn​),σ2).

The best function is immediate: set f(xn)=ynf(x_n) = y_nf(xn​)=yn​ at every training input, making every residual zero. The likelihood is then

p(y∣f,σ2)=(2πσ2)−N/2  ⟶  ∞as σ2→0.p(y\mid f,\sigma^2) = (2\pi\sigma^2)^{-N/2} \;\longrightarrow\; \infty \qquad\text{as } \sigma^2\to0 .p(y∣f,σ2)=(2πσ2)−N/2⟶∞as σ2→0.

The maximum does not exist. This is exactly the collapsing-variance degeneracy of Lecture 5: the model "explains" the data by memorizing it and then declaring there was no noise at all. Any hyperparameters fitted this way are meaningless.

The lesson is not that the objective was wrong but that the function is far too flexible an object to choose by maximization. A GP has, in effect, infinitely many parameters. Optimizing them all will always produce interpolation and zero noise.

2.3 The fix: average over the function instead of maximizing over it

Replace the question

How well does the best function explain the data?

with

How well does a typical function drawn from my prior explain the data, on average?

That is, average the likelihood over the prior rather than maximizing it:

 p(y∣θ)  =  ∫p(y∣f,σ2)  p(f∣θ)  df. \boxed{\ p(y\mid\theta) \;=\; \int p(y\mid f,\sigma^2)\;p(f\mid\theta)\;df .\ } p(y∣θ)=∫p(y∣f,σ2)p(f∣θ)df. ​

This is the marginal likelihood, or the evidence. "Marginal" because fff has been marginalized — integrated out — rather than optimized.

Two properties make it the right training objective.

It cannot memorize. A single perfectly-fitting function no longer wins the day, because it is one function among all those the prior allows, weighted by how plausible the prior considers it. No amount of flexibility lets a model cheat an average.

It is an ordinary likelihood. It is the probability of the observed data as a function of the remaining unknowns θ\thetaθ — precisely the kind of object Lecture 4 maximized. So maximizing it is simply maximum likelihood, applied one level up. The name for this is type-II maximum likelihood, or empirical Bayes.

In one line: Bayes for the function, maximum likelihood for the hyperparameters.

2.4 Computing it

The integral looks forbidding and is not. From Step 1, at the training inputs,

y=f+ϵ,f∼N(0,Kθ),ϵ∼N(0,σ2I),f⊥ϵ.y = f+\epsilon, \qquad f\sim\mathcal{N}(0,K_\theta), \qquad \epsilon\sim\mathcal{N}(0,\sigma^2 I), \qquad f\perp\epsilon .y=f+ϵ,f∼N(0,Kθ​),ϵ∼N(0,σ2I),f⊥ϵ.

A sum of independent Gaussians is Gaussian, with covariances adding. So without doing any integral at all,

 p(y∣θ)=N(y ∣ 0, Cθ),Cθ=Kθ+σ2I. \boxed{\ p(y\mid\theta) = \mathcal{N}\big(y\,\big|\,0,\ C_\theta\big), \qquad C_\theta = K_\theta+\sigma^2 I .\ } p(y∣θ)=N(y∣∣​0, Cθ​),Cθ​=Kθ​+σ2I. ​

Taking logarithms,

log⁡p(y∣θ)  =  −12 y⊤Cθ−1y⏟data fit  −  12log⁡∣Cθ∣⏟complexity penalty  −  N2log⁡2π.\log p(y\mid\theta) \;=\; \underbrace{-\tfrac12\,y^\top C_\theta^{-1}y}_{\text{data fit}}\;\underbrace{-\;\tfrac12\log\big|C_\theta\big|}_{\text{complexity penalty}}\;-\;\tfrac N2\log2\pi .logp(y∣θ)=data fit−21​y⊤Cθ−1​y​​complexity penalty−21​log∣∣​Cθ​∣∣​​​−2N​log2π.

2.5 Why this picks sensible hyperparameters

Go back to the question in §2.3 — how well does a typical prior function explain the data? — and run it for three length scales.

  • Length scale too short. Prior draws wiggle violently. Almost every particular draw wiggles the wrong way at most of the data points. Averaged over draws: a poor fit.
  • Length scale too long. Prior draws are nearly flat. If the data vary at all, almost every draw misses them. Averaged: also a poor fit.
  • Length scale about right. A good fraction of prior draws follow the general shape of the data. Averaged: a good fit.

The marginal likelihood is largest in the third case. It selects the simplest model that still explains the data — Occam's razor — and nobody added a complexity penalty by hand. The penalty is a consequence of averaging.

The same idea explains the two terms in the formula. p(y∣θ)p(y\mid\theta)p(y∣θ) is a probability distribution over all possible datasets y∈RNy\in\mathbb{R}^Ny∈RN, so it integrates to one. A flexible model can produce a huge variety of datasets, spreads its probability thinly over them, and therefore assigns only a little to the one actually observed: that shows up as a large log⁡∣Cθ∣\log|C_\theta|log∣Cθ​∣, penalized. A rigid model concentrates probability on a narrow set of smooth datasets; if the observed data is not among them, y⊤Cθ−1yy^\top C_\theta^{-1}yy⊤Cθ−1​y is large, penalized. The maximum balances the two.

2.6 The same recipe closes a gap from Lecture 7

Lecture 7 left σ2\sigma^2σ2 and τ2\tau^2τ2 unexplained: the posterior formulas assumed them known. Bayesian linear regression is a GP with the linear kernel k=τ2ϕ⊤ϕ′k = \tau^2\phi^\top\phi'k=τ2ϕ⊤ϕ′, whose Gram matrix is K=τ2ΦΦ⊤K = \tau^2\Phi\Phi^\topK=τ2ΦΦ⊤, so its marginal likelihood is

p(y∣σ2,τ2)=N(y ∣ 0, τ2ΦΦ⊤+σ2I).p(y\mid\sigma^2,\tau^2) = \mathcal{N}\big(y\,\big|\,0,\ \tau^2\Phi\Phi^\top+\sigma^2 I\big).p(y∣σ2,τ2)=N(y∣∣​0, τ2ΦΦ⊤+σ2I).

Maximizing over (σ2,τ2)(\sigma^2,\tau^2)(σ2,τ2) chooses them both. Since the ridge penalty is λ=σ2/τ2\lambda = \sigma^2/\tau^2λ=σ2/τ2, this also chooses the ridge penalty — with no cross-validation and no data held out.

2.7 Doing the optimization

Training is now an optimization problem, and Lecture 6 supplies the tools.

Optimize the logarithms. All three hyperparameters are positive, and they often differ by orders of magnitude. Optimizing (log⁡σf2,log⁡ℓ,log⁡σ2)(\log\sigma_f^2,\log\ell,\log\sigma^2)(logσf2​,logℓ,logσ2) makes the problem unconstrained and much better behaved.

Use L-BFGS or gradient descent with the exact gradient. With α=Cθ−1y\alpha = C_\theta^{-1}yα=Cθ−1​y,

∂log⁡p(y∣θ)∂θj  =  12tr⁡ ⁣((αα⊤−Cθ−1)∂Cθ∂θj),\frac{\partial \log p(y\mid\theta)}{\partial\theta_j} \;=\; \frac12\operatorname{tr}\!\Big(\big(\alpha\alpha^\top - C_\theta^{-1}\big)\frac{\partial C_\theta}{\partial\theta_j}\Big),∂θj​∂logp(y∣θ)​=21​tr((αα⊤−Cθ−1​)∂θj​∂Cθ​​),

which needs only ∂Cθ/∂θj\partial C_\theta/\partial\theta_j∂Cθ​/∂θj​, an elementwise derivative of the kernel. Check it against finite differences before trusting it.

Restart from several initializations. The marginal likelihood is not concave, and a specific pair of competing explanations shows up repeatedly: a short length scale with small noise, in which the function wiggles through every observation, and a long length scale with large noise, in which a smooth trend is seen through heavy scatter. Both can be local maxima of the same objective on the same data. Compare their marginal likelihoods, and look at both fits — occasionally the data genuinely cannot decide, and that is worth knowing rather than hiding.

Two cautions. This is maximum likelihood, so with many hyperparameters it can overfit. And the evidence only compares the kernels you offered it: it cannot tell you that all of them are wrong. It does not replace a held-out test set.

3. Step 3 — Inference: predictions at test points

3.1 The joint, and the conditional

We want the distribution of f⋆=f(x⋆)f^\star = f(x^\star)f⋆=f(x⋆) given the data. Under the model, the training targets and the test function value are jointly Gaussian; their covariances come straight from the kernel, with noise on the training targets only:

(yf⋆)∼N(0, (K+σ2Ik⋆k⋆⊤k⋆⋆)).\begin{pmatrix}y\\f^\star\end{pmatrix}\sim\mathcal{N}\left(0,\ \begin{pmatrix}K+\sigma^2 I & k^\star\\ k^{\star\top} & k^{\star\star}\end{pmatrix}\right).(yf⋆​)∼N(0, (K+σ2Ik⋆⊤​k⋆k⋆⋆​)).

Apply the Gaussian conditioning formula from Lecture 2 — for zero-mean jointly Gaussian (z1,z2)(z_1,z_2)(z1​,z2​), z1∣z2∼N(Σ12Σ22−1z2, Σ11−Σ12Σ22−1Σ21)z_1\mid z_2\sim\mathcal{N}\big(\Sigma_{12}\Sigma_{22}^{-1}z_2,\ \Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}\big)z1​∣z2​∼N(Σ12​Σ22−1​z2​, Σ11​−Σ12​Σ22−1​Σ21​) — with z1=f⋆z_1 = f^\starz1​=f⋆ and z2=yz_2 = yz2​=y:

 f⋆∣D∼N(μ⋆,v⋆),μ⋆=k⋆⊤(K+σ2I)−1y,v⋆=k⋆⋆−k⋆⊤(K+σ2I)−1k⋆. \boxed{\ f^\star\mid\mathcal{D}\sim\mathcal{N}(\mu^\star,v^\star), \quad \mu^\star = k^{\star\top}\big(K+\sigma^2I\big)^{-1}y, \quad v^\star = k^{\star\star}-k^{\star\top}\big(K+\sigma^2I\big)^{-1}k^\star .\ } f⋆∣D∼N(μ⋆,v⋆),μ⋆=k⋆⊤(K+σ2I)−1y,v⋆=k⋆⋆−k⋆⊤(K+σ2I)−1k⋆. ​

For a new noisy observation, add the noise back: y⋆∣D∼N(μ⋆, v⋆+σ2)y^\star\mid\mathcal{D}\sim\mathcal{N}\big(\mu^\star,\ v^\star+\sigma^2\big)y⋆∣D∼N(μ⋆, v⋆+σ2).

That is the whole of GP prediction. No weights, no optimization, no step size — just the conditional of a joint Gaussian.

For several test inputs at once, replace k⋆k^\stark⋆ by the N×MN\times MN×M matrix K⋆K_\starK⋆​ and k⋆⋆k^{\star\star}k⋆⋆ by the M×MM\times MM×M matrix K⋆⋆K_{\star\star}K⋆⋆​; the mean becomes a vector and the variance a full covariance K⋆⋆−K⋆⊤(K+σ2I)−1K⋆K_{\star\star}-K_\star^\top(K+\sigma^2I)^{-1}K_\starK⋆⋆​−K⋆⊤​(K+σ2I)−1K⋆​, from which joint samples are drawn by Cholesky exactly as prior samples were.

3.2 Reading the mean

Using α=(K+σ2I)−1y\alpha = (K+\sigma^2I)^{-1}yα=(K+σ2I)−1y stored at training time,

μ⋆=∑n=1Nαn k(xn,x⋆).\mu^\star = \sum_{n=1}^{N}\alpha_n\,k(x_n,x^\star).μ⋆=n=1∑N​αn​k(xn​,x⋆).

The prediction is a weighted sum of kernel functions, one centered at each training input, with weights fixed during training. The model began with infinitely many features, and its predictions live in an NNN-dimensional space determined by the data. Models whose effective size grows with the data are called nonparametric.

With the linear kernel this equals Lecture 7's posterior mean mN⊤ϕ⋆m_N^\top\phi^\starmN⊤​ϕ⋆, which equals the ridge estimate of Lecture 5. The same prediction has now appeared three times under three names.

3.3 Reading the variance

v⋆=k⋆⋆⏟prior variance  −  k⋆⊤(K+σ2I)−1k⋆⏟removed by the data ≥ 0.v^\star = \underbrace{k^{\star\star}}_{\text{prior variance}}\;-\;\underbrace{k^{\star\top}\big(K+\sigma^2I\big)^{-1}k^\star}_{\text{removed by the data}\ \ge\ 0}.v⋆=prior variancek⋆⋆​​−removed by the data ≥ 0k⋆⊤(K+σ2I)−1k⋆​​.

Three consequences, all of which matter for the next three lectures.

It reverts to the prior far from the data. With a stationary kernel, k(xn,x⋆)→0k(x_n,x^\star)\to0k(xn​,x⋆)→0 as x⋆x^\starx⋆ moves away from every training input, so k⋆→0k^\star\to0k⋆→0 and

μ⋆→0,v⋆→k⋆⋆=σf2.\mu^\star\to0, \qquad v^\star\to k^{\star\star} = \sigma_f^2 .μ⋆→0,v⋆→k⋆⋆=σf2​.

Compare the failure that opened Lecture 8. The mean still returns to zero — the prior mean, which is fine. What changed is the variance: the model now reports the full prior uncertainty rather than claiming certainty. It says I don't know. That repair came from the prior, not from the data.

It does not depend on yyy. Only input locations appear in v⋆v^\starv⋆. You can compute where the model will be uncertain before taking any measurements — which is exactly what Bayesian optimization and experimental design exploit.

It splits the two uncertainties. For a new observation,

Var⁡[y⋆∣D]=σ2⏟aleatoric+v⋆⏟epistemic.\operatorname{Var}[y^\star\mid\mathcal{D}] = \underbrace{\sigma^2}_{\text{aleatoric}}+\underbrace{v^\star}_{\text{epistemic}} .Var[y⋆∣D]=aleatoricσ2​​+epistemicv⋆​​.

The aleatoric part is constant and irreducible; the epistemic part is small near data, grows between and beyond it, and tends to σf2\sigma_f^2σf2​ far away. Where data are dense, v⋆→0v^\star\to0v⋆→0 and only σ2\sigma^2σ2 remains: you can learn the function exactly and still not predict the next measurement exactly.

Algorithm: GP inference

After training, each mean costs O(N)O(N)O(N) and each variance O(N2)O(N^2)O(N2); the O(N3)O(N^3)O(N3) was paid once.

Plot functions, not only bands. A band μ⋆±2v⋆\mu^\star\pm2\sqrt{v^\star}μ⋆±2v⋆​ shows the uncertainty at each input separately and conceals how values at different inputs move together. Two models with nearly identical bands — a Matérn-1/2 and a squared-exponential GP on the same data — believe in completely different functions, one jagged and one smooth. Always overlay a handful of joint posterior samples using the multi-point form of §3.1.

4. Kernel design in practice

The kernel is the model. Everything you believe about the function is expressed there, so it is worth knowing how to build one for a problem with structure.

4.1 Composition: adding and multiplying kernels

Sums and products of valid kernels are valid (Lecture 8 §4.1), and each has a reading.

A sum is an "or". If f1∼GP(0,k1)f_1\sim\mathcal{GP}(0,k_1)f1​∼GP(0,k1​) and f2∼GP(0,k2)f_2\sim\mathcal{GP}(0,k_2)f2​∼GP(0,k2​) independently, then f1+f2∼GP(0,k1+k2)f_1+f_2\sim\mathcal{GP}(0,k_1+k_2)f1​+f2​∼GP(0,k1​+k2​). Use a sum when the function is a superposition of distinct behaviors on different scales: a slow trend plus short-term fluctuation is kSE(ℓlong)+kSE(ℓshort)k_{\mathrm{SE}}(\ell_{\text{long}})+k_{\mathrm{SE}}(\ell_{\text{short}})kSE​(ℓlong​)+kSE​(ℓshort​), and each component gets its own amplitude and length scale, all fitted by the marginal likelihood.

A product is an "and". k1k2k_1k_2k1​k2​ is large only where both factors are large, so it expresses a conjunction of conditions. The standard use is to localize a global structure: kper×kSEk_{\mathrm{per}}\times k_{\mathrm{SE}}kper​×kSE​ is locally periodic — a cycle whose shape drifts slowly over a length scale set by the SE factor, rather than repeating exactly forever.

The canonical worked example is atmospheric CO2_22​: a long-term trend (kSEk_{\mathrm{SE}}kSE​, large ℓ\ellℓ), plus a seasonal cycle that slowly changes shape (kper×kSEk_{\mathrm{per}}\times k_{\mathrm{SE}}kper​×kSE​), plus medium-scale irregularities, plus noise. Each term is a sentence about the physics, and each of its hyperparameters is a quantity you can read off after fitting and check against what you know.

This is the payoff of the function-space view. Model building becomes a matter of composing statements about covariance, rather than guessing a basis. And every constituent is fitted by the same Step 2.

4.2 Several input dimensions: ARD

For x∈Rdx\in\mathbb{R}^dx∈Rd, the natural generalization gives each input dimension its own length scale:

k(x,x′)=σf2exp⁡(−12∑i=1d(xi−xi′)2ℓi2).k(x,x') = \sigma_f^2\exp\left(-\frac12\sum_{i=1}^{d}\frac{(x_i-x_i')^2}{\ell_i^2}\right).k(x,x′)=σf2​exp(−21​i=1∑d​ℓi2​(xi​−xi′​)2​).

Fitting the ℓi\ell_iℓi​ by marginal likelihood does something useful automatically. If the function barely varies along dimension iii, the evidence is maximized by making ℓi\ell_iℓi​ large — so large that the kernel becomes effectively constant in that coordinate and the dimension is ignored. Small ℓi\ell_iℓi​ means that input matters a great deal.

Automatic relevance determination (ARD). Fitted inverse length scales 1/ℓi1/\ell_i1/ℓi​ rank the input dimensions by how much the function depends on them.

Two practical notes. Standardize your inputs before fitting, so that the ℓi\ell_iℓi​ start on a comparable footing and the optimization is well behaved; standardize or center yyy too, which is part of what justifies the zero mean function. And ARD adds ddd hyperparameters, so in high dimensions the caution of §2.7 about overfitting the evidence becomes real.

4.3 Mean functions

Nothing required m(x)=0m(x) = 0m(x)=0. With a general mean function the predictive becomes

f⋆∣D∼N(m(x⋆)+k⋆⊤(K+σ2I)−1(y−m(X)),  v⋆),f^\star\mid\mathcal{D}\sim\mathcal{N}\Big(m(x^\star)+k^{\star\top}\big(K+\sigma^2I\big)^{-1}\big(y-m(X)\big),\ \ v^\star\Big),f⋆∣D∼N(m(x⋆)+k⋆⊤(K+σ2I)−1(y−m(X)),  v⋆),

with the variance unchanged. Since a stationary GP reverts to its mean far from data (§3.3), the mean function is exactly the knob controlling extrapolation. If you know the function should grow linearly, or should approach a known physical asymptote, put that in mmm and let the GP model the deviation from it. A zero mean is a claim, not a default — it is only innocuous after you have centered yyy.

4.4 Noise: the other half of the model

σ2\sigma^2σ2 is a modeling assumption like everything else.

Deterministic simulators. If the data come from a code that returns the same output for the same input, there is no observation noise: take σ2→0\sigma^2\to0σ2→0, so that the posterior mean interpolates the data exactly and v⋆=0v^\star = 0v⋆=0 at every training input. You will then certainly need jitter. This is the standard setting for surrogate modeling, and it is where the next lecture begins.

Input-dependent noise. If the noise level varies with xxx and you know the variances, replace σ2I\sigma^2 Iσ2I by diag⁡(σ12,…,σN2)\operatorname{diag}(\sigma_1^2,\dots,\sigma_N^2)diag(σ12​,…,σN2​); every formula above is unchanged. Learning an unknown noise function is harder and takes us outside the exact GP.

5. What goes wrong, and how to recognize it

The fitted hyperparameters are interpretable, so read them before looking at any plot.

σ^2\hat\sigma^2σ^2 has absorbed everything. The fitted noise is close to the variance of yyy, and ℓ^\hat\ellℓ^ is huge. The model has concluded the data is pure noise around a constant. Either the kernel cannot express the structure that is there, or the optimizer landed in the long-length-scale local maximum (§2.7). Restart, and check whether a different kernel is needed.

ℓ^\hat\ellℓ^ is tiny and σ^2\hat\sigma^2σ^2 near zero. The posterior interpolates every point and reverts to the prior between them: the model has memorized rather than generalized. This is the other local maximum. It is also what you get if the data really is that rough, so compare marginal likelihoods and look at the samples before deciding.

The Cholesky factorization keeps failing. Add jitter first. If it persists, look for duplicated or nearly duplicated inputs, which make rows of KKK identical.

Extrapolation is useless. Away from the data a stationary GP returns the mean function with full prior variance. That is honest, and if you need something better the fix is §4.3's mean function or a non-stationary kernel — not more data of the same kind.

High-dimensional inputs. In high dimensions, distances between random points concentrate: everything is roughly equidistant from everything else, so k⋆k^\stark⋆ is nearly constant and the posterior barely differs from the prior anywhere. Stationary GPs with ARD work well up to tens of input dimensions, not thousands.

NNN is too large. The O(N3)O(N^3)O(N3) factorization is the binding constraint past roughly 10410^4104 points, at which stage you need sparse or approximate methods.

Set this beside Lecture 7. The model moved from a prior on weights to a prior on functions. Training moved from "compute the posterior, assuming σ2\sigma^2σ2 and τ2\tau^2τ2 are known" to "fit the hyperparameters by maximum marginal likelihood." And inference now produces uncertainty that is honest everywhere, because the prior never claimed certainty anywhere.

Where this goes. The next three lectures consume exactly the two numbers μ⋆\mu^\starμ⋆ and v⋆v^\starv⋆.

  • Multi-fidelity modeling. When a cheap approximate simulator and an expensive accurate one are both available, a GP can be built whose kernel couples them, so that many cheap runs sharpen predictions about the expensive one.
  • Bayesian optimization. To minimize an expensive function, choose each next evaluation by trading a promising μ⋆\mu^\starμ⋆ against a large v⋆v^\starv⋆.
  • Active learning and experimental design. Choose measurements to reduce v⋆v^\starv⋆ where it matters — possible precisely because v⋆v^\starv⋆ does not depend on yyy.

P2. Two GPs are fitted to data from a smooth function: one with ℓ=0.05\ell = 0.05ℓ=0.05, one with ℓ=1\ell = 1ℓ=1. Both can pass through every data point. Which has the higher marginal likelihood, and why?
